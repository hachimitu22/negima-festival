# ゲーム概要

## コンセプト

本作は『魔法先生ネギま！』の麻帆良祭を題材に、祭りの三日間を体験するゲームである。

プレイヤーはネギ・スプリングフィールドとなり、教師としての役目を果たしながら学園都市を巡る。
生徒との交流、祭りで起きる出来事への対応、物語の真相の追跡など、何を優先するかはプレイヤーが選ぶ。

## 基本的な遊び方

プレイヤーはマップ上の場所を移動し、そこにいる人物と会話し、発生したイベントや教師としての仕事に対応する。
行動中もゲーム内時間は進み、人物はそれぞれ学園内を移動する。

麻帆良祭は1日目AM10に始まり、ゲーム内時間で三日間続く。
プレイヤーはカシオペアを使って時間を戻せるため、同じ三日間を異なる行動で繰り返し体験できる。

基本的な流れは次のとおり。

1. マップで現在地と周囲の人物を確認する。
2. 場所を移動する、または同じ場所にいる人物と会話する。
3. 会話を通じて人物との関係を深め、イベントを開始する。
4. 定期的に発生する教師の仕事にも対応する。
5. イベントの目的を達成して、好感度やMahoPayポイントなどの報酬を得る。
6. 必要に応じてカシオペアで時間を戻し、別の行動を試す。

## 主なゲームシステム

### 三日間

麻帆良祭の開始時刻を1日目AM10とし、開始から終了までを72時間として扱う。
時間の経過によって、人物の居場所や実行できる出来事が変化する。

### カシオペア

魔力を消費してゲーム内時間を最大24時間戻す。
戻す時間が長いほど、消費する魔力は多くなる。
時間を戻してもすべてが元に戻るわけではなく、繰り返しの中で維持される情報もある。

### 会話

同じ場所にいる人物と会話できる。
会話中の選択や会話の完了によって、生徒との好感度やイベントの状態が変化する。

### MahoPayポイント

イベントの報酬などで獲得する、麻帆良祭中のゲーム内通貨である。
カシオペアで時間を戻しても、獲得済みのポイントは維持される。

### イベント

会話をきっかけとして配達や同行が発生し、ゲーム時間に応じて見回りが発生する。
実行中のイベントはマップを移動しながら達成する。

## プロトタイプ

現在はブラウザ上で動作するコマンド選択式のプロトタイプとして開発する。
DOMによる画面はゲーム挙動を確認するための暫定的な描画手段であり、完成形のUIを示すものではない。
