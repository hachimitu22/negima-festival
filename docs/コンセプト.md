# コンセプト
ネギま！の麻帆良祭を題材にしたゲームが存在せず
麻帆良祭のドタバタを体験することを目指す。
ネギ先生となり先生の役目を果たしつつ祭りを通じて生徒達と交流を深める。

麻帆良祭は3日間(72時間)、カシオペアの効果で3日間を繰り返す。
先生として職務を全うするもよし、生徒と交流を深めるもよし、物語の真相を追うもよし、とにかく麻帆良祭を楽しむ。

基本は先生としてのタスクをこなすため学園都市を奔走しつつランダムに発生するハプニングに対応していく。
原作のストーリーを踏襲したイベントや独自のイベントも発生する。

## プロトタイプ版
ブラウザ上で動作するコマンド選択式のゲームとする。

### 描画方針
現状では描画すべき絵素材が存在しないため、即時性を優先してDOMで画面を構成する。
DOMによるviewは最終目的ではなく、ゲーム進行、イベント処理、状態遷移を素早く確認するためのプロトタイプ描画手段とする。

一般的なゲームとしての見通しを良くするため、将来的にはcanvasなどに描画する形式を候補とする。
そのため、ゲームロジックはDOMに依存させず、状態のsnapshotをviewまたはrendererが受け取って描画する構造を維持する。
DOM viewを実装する場合も、canvas rendererへ差し替えられる境界を意識する。
