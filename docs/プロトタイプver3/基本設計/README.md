# プロトタイプver3 基本設計

## 目的

プロトタイプver3で最初に実現するゲーム体験と、実現に必要なシステムの境界を定める。
既存プロトタイプの全機能を引き継がず、短い代表イベントを通して、場所、登場人物、会話、報酬、時間巻き戻しが連携する構造を確認する。

## 位置づけ

- プロトタイプver3は、既存実装を段階的に改修せず、新しいゲーム実装として構築する。
- 既存のCanonicalプロトタイプは挙動確認用に凍結し、プロトタイプver3の仕様または実装の正本にしない。
- 既存のゲームエンジンが提供するシーン、入力、snapshot、rendererの境界だけを再利用対象とする。
- プロトタイプver3完成後は新実装を既定起動とし、凍結したプロトタイプには起動入口を設けない。

## 最初の完成範囲

次の一連の体験を最初の完成範囲とする。

```text
場所を選んで移動する
↓
場所への進入によってイベントが始まる
↓
登場人物がイベント上の位置へ移動する
↓
会話する
↓
ゲーム内時間が進む
↓
MahoPayポイントを獲得する
↓
カシオペアで過去の時刻を選んで巻き戻す
↓
イベントを再実行する
```

## 対象外

- 既存プロトタイプにあるイベントの移植
- 三日間全体の進行
- セーブとロード
- 複数イベントの同時進行
- 分岐イベント
- NPCの自律巡回
- 最終版の画面表現
- 汎用的な通知配信基盤

## 詳細設計との境界

このディレクトリではプレイヤーから見た挙動、ゲームルール、システムの役割を定める。
