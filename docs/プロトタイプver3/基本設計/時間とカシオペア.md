# プロトタイプver3 時間とカシオペア

## 目的

場所移動による時間経過と、スケジュールの認知状態を維持してゲームの状態を記録済みの時刻へ戻す簡易巻き戻しを定める。

## ゲーム内時刻

- 1日目10:00から開始する。
- 場所を1回移動すると5分進む。
- プロトタイプver3では日付をまたぐ進行を扱わない。

## 簡易巻き戻し

- 10:00より後かつ会話中でない場合、時刻欄から「10:00に戻す」を選べる。
- 実行するとゲーム内時刻と巻き戻し対象の状態を、記録した1日目10:00時点へ戻す。
- 10:00および会話中は実行できない。
- 巻き戻し操作によって時刻到達イベントを発生させない。
- 巻き戻し直後の更新ではActorを移動させない。

## 巻き戻し時の状態

- プレイヤーの現在地は維持し、NPCの現在地は記録した位置へ戻す。
- 全イベントの実行状態を記録した状態へ戻す。10:00時点で待機中だったイベントは、開始条件を再び満たすと開始できる。
- 一度認知したスケジュールは、巻き戻し後もスケジュール帳へ表示する。
- スケジュールの有効状態と実行状態を記録した状態へ戻す。

スケジュールの認知状態は実行判定および実行状態から独立する。認知していないスケジュールも実行でき、認知済みでも現在ループで無効なスケジュールは実行しない。

同じループ中では完了済みイベントを再実行できない。

## 対象外

- 巻き戻し先の選択
- 10:00以外の時刻の記録と、会話・イベント実行中の記録
- MP消費
- ループ数
- 報酬と永続状態

## 他システムとの関係

- 場所移動は[ゲーム体験範囲](ゲーム体験範囲.md)に従う。
- ClockSystemが時刻と簡易巻き戻し可否を管理する。
- DOM rendererはSceneSnapshotの可否だけを参照して操作を表示する。
