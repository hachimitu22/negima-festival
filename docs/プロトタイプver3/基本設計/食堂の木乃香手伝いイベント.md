# 食堂の木乃香手伝いイベント

## 目的

指定時間に食堂の木乃香へ話しかけ、手伝い方の選択によって異なる会話結果を得るイベントを提供する。

## 開始条件

次の条件をすべて満たしたときに開始する。

- 6月20日10:30から10:45までに話しかける。
- プレイヤーと木乃香が食堂にいる。
- イベントを完了していない。
- 別のイベントまたは会話を実行していない。

受付時間は10:30と10:45を含む。

## 進行

1. 木乃香から食堂の手伝いを頼まれる。
2. プレイヤーが手伝い方を選ぶ。
3. 選択した手伝いに対応する会話を進める。
4. 会話を最後まで進めるとイベントを完了する。

## 選択肢と結果

### 料理を運ぶ

- 選択肢「料理を運びます」
- ネギが料理の配膳を手伝う。
- 木乃香から、待っている客へ料理を届けられたことを感謝される。

### 食器を片づける

- 選択肢「食器を片づけます」
- ネギが食器の片づけを手伝う。
- 木乃香から、次の客を案内できるようになったことを感謝される。

## 終了条件

- 分岐後の会話を最後まで進めると完了履歴を残す。
- 完了後に木乃香へ話しかけた場合は通常会話を開始する。
- 受付時間外に木乃香へ話しかけた場合も通常会話を開始する。

## 他システムとの関係

- 木乃香は受付時間中、食堂に滞在する。
- 会話中は時間を進めない。
- EventSystemは開始条件と完了履歴を管理する。
- DialogueSystemは選択肢と分岐後の会話を管理する。
