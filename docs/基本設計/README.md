# 基本設計

このディレクトリは、意図したゲーム挙動の基本設計を管理する正本である。
一般的なゲームの説明書のように、ゲーム内に存在する概念、遊び方、プレイヤーから直接見えない条件を含む全ルールを記述する。
ゲームを実現するためのプログラム構造は[詳細設計](../詳細設計/README.md)で扱う。

## 共通テンプレート

新しい仕様書には次の項目を設ける。

1. 文書情報
2. 目的
3. 関係する用語
4. 開始条件と終了条件
5. ルール
6. 状態遷移
7. 他システムとの関係
8. 具体例
9. 未決事項

項目が不要な場合は省略せず「なし」と記載し、考慮済みであることを明確にする。
