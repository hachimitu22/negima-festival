# イベント

## 文書情報

- 仕様状態: 確定
- 実装状況: 実装済み

## 目的

会話だけでは完結しない目的をプレイヤーへ提示し、マップ移動と人物との交流を結び付ける。

## イベントとタスク

イベントはゲーム内で起きる出来事全体を表す。
タスクはイベントによって発生する、達成すべき目的を表す。
通常会話のように継続する目的を持たない単発イベントも存在する。

この分類はゲーム内概念の整理であり、実装上の共通クラスや継承関係を要求しない。

## 共通ルール

- 継続する実行中イベントは最大1件とする。
- 配達と同行を同時に実行できない。
- 実行中イベントがない場合だけ、新しい継続イベントを会話候補へ加える。
- 実行中イベントはメインゲーム中に確認できる。
- 完了または失敗したイベントは実行中イベントとして保持しない。
- カシオペアを使用すると実行中イベントを破棄する。
- イベントの開始、状態変更、完了は関連する会話の完了時に一度だけ行う。

## イベントの選出

実行中イベントがない場合、通常会話の候補に配達依頼と同行開始をそれぞれ1候補追加する。
候補全体から均等に1件を選出する。

実行中イベントがある場合は、新しい配達または同行を開始しない。
