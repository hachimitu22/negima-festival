# イベント

## 文書情報

- 仕様状態: 確定

## 目的

会話だけでは完結しない目的をプレイヤーへ提示し、マップ移動と人物との交流を結び付ける。

## イベントとタスク

イベントはゲーム内で起きる出来事全体を表す。
タスクはイベントによって発生する、達成すべき目的を表す。
通常会話のように継続する目的を持たない単発イベントも存在する。

この分類はゲーム内概念の整理であり、実装上の共通クラスや継承関係を要求しない。

## 共通ルール

- 会話を起点とする配達または同行の実行中イベントは最大1件とする。
- 時間を起点とする見回りの実行中イベントは最大1件とする。
- 時間、場所移動、選択肢を起点とする分岐イベントは最大1件とする。
- 配達または同行1件と、見回り1件と、分岐イベント1件は並行して実行できる。
- 実行中イベント全体では最大3件とする。
- 配達と同行を同時に実行できない。
- 実行中の配達または同行がない場合だけ、新しい配達と同行を会話候補へ加える。
- 実行中の見回りは、配達と同行の会話候補を妨げない。
- 実行中の分岐イベントは、配達、同行、見回りの進行や会話候補を妨げない。
- 実行中イベントはメインゲーム中に確認できる。
- 完了または失敗したイベントは実行中イベントとして保持しない。
- カシオペアを使用すると実行中イベントを破棄する。
- 会話を起点とするイベントの開始、状態変更、完了は関連する会話の完了時に一度だけ行う。
- 見回りの開始と進捗は、ゲーム時間と場所移動によって決定する。
- 連絡掲示の開始、進捗、分岐は、ゲーム時間と場所移動によって決定する。
- 展示トラブル対応の開始、進捗、分岐は、連絡掲示の完了、選択肢、ゲーム時間、場所移動によって決定する。

## イベントの選出

実行中の配達または同行がない場合、通常会話の候補に配達依頼と同行開始をそれぞれ1候補追加する。
候補全体から均等に1件を選出する。

実行中の配達または同行がある場合は、新しい配達または同行を開始しない。
見回りは会話候補に含めず、[見回りイベント](見回りイベント.md)で定めるゲーム時間に自動で開始する。
連絡掲示は会話候補に含めず、[連絡掲示イベント](連絡掲示イベント.md)で定めるゲーム時間と場所移動によって進行する。
展示トラブル対応は会話候補に含めず、[展示トラブル対応イベント](展示トラブル対応イベント.md)で定める選択肢、ゲーム時間、場所移動によって進行する。
