# 3-Aホラーハウス

3-Aの出し物で暗い一本道を探索するイベント。

## 内容

簡単、普通、難しいの3コースから選択し、パニックメーターを管理しながら出口を目指す。パニックが最大になるとゴールまで走り抜ける。

## 発生エリア

校舎エリア内の3-Aホラーハウス。

## 時刻

### 開始時間

1ループ目AM10:00。

### 受付終了時間

固定進行のため該当なし。

### 終了時間 または 経過時間

終了時にAM11:00へ進む。

## 発生条件

導入イベントで3-Aへ移動すると発生する。

## フロー

```mermaid
flowchart TD
  start[3-Aへ移動] --> select{コースを選択}
  select --> haunted[暗い一本道を探索<br/>ID: haunted-house]
  haunted --> scare[驚かし演出・パニック値更新]
  scare --> panic{パニック最大?}
  panic -->|いいえ| clear[出口へ到達<br/>クリア記録]
  panic -->|はい| run[パニックで走り抜ける<br/>ID: haunted-house-panic-run]
  clear --> result[結果を記録<br/>ID: haunted-house-result]
  run --> result
  result --> next[AM11:00に保健室へ進む]
```

- 実装ID: `haunted-house`、`haunted-house-panic-run`、`haunted-house-result`
- クリア、未クリアの結果を記録する。
- 未クリアコースの再挑戦機能は実装済み。
