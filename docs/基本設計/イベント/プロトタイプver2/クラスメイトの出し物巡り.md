# クラスメイトの出し物巡り

4ループ目にクラスメイトの出し物を順に体験するイベント。

## 内容

対象クラスメイトの出し物エリアへ移動して会話する。8人分の出し物を体験済みとして記録する。

## 発生エリア

グラウンド、クラブ棟、ホール、屋台通り、食堂街。

## 時刻

### 開始時間

4ループ目AM11:30。

### 受付終了時間

出し物はAM10:00からPM2:00まで。実装上、出し物巡り自体はPM6:00までの予定として扱われる。

### 終了時間 または 経過時間

全対象者との会話完了時。

## 発生条件

1日目反省会後、4ループ目AM11:30へ巻き戻ると発生する。
