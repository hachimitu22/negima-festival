# 小太郎・あやかとの出し物巡り

3-Aホラーハウスの客引きから分岐して発生する同行イベント。

## 内容

4ループ目AM11:30から正午まで3-Aホラーハウスの客引きを手伝う。条件を満たすとあやかと合流し、クラスメイトの出し物を巡る。

## 発生エリア

校舎エリア、クラスメイトの出し物エリア。

## 時刻

### 開始時間

4ループ目AM11:30。

### 受付終了時間

客引きの受付終了はPM12:00。同行イベントはPM6:00まで。

### 終了時間 または 経過時間

PM6:00、または出し物巡りの完了時。

## 発生条件

4ループ目に小太郎が同行している状態で、客引きを手伝うと発生する。

## フロー

```mermaid
flowchart TD
  help[3-Aホラーハウス客引きを手伝う] --> condition{小太郎が同行中?}
  condition -->|いいえ| finish[客引きのみで終了]
  condition -->|はい| ayaka[あやかと合流<br/>ID: kotaro-ayaka-attraction-tour]
  ayaka --> tour[クラスメイトの出し物を巡る<br/>ID: ayaka-attraction-tour]
  tour --> end[PM6:00までの同行イベント終了]
```

- 実装ID: `ayaka-attraction-tour`、進行段階ID `kotaro-ayaka-attraction-tour`
- 小太郎がいない場合は客引きのみで終了する。
- あやかルートの詳細な個別出し物ミニゲームは未実装。
