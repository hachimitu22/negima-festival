# 小太郎・あやかとの出し物巡り

3-Aホラーハウスの客引きから分岐して発生する同行イベント。

## 内容

4ループ目AM11:30から正午まで3-Aホラーハウスの客引きを手伝う。条件を満たすとあやかと合流し、クラスメイトの出し物を巡る。

## 発生エリア

校舎エリア、クラスメイトの出し物エリア。

## 時刻

### 開始時間

4ループ目AM11:30。

### 受付終了時間

客引きの受付終了はPM12:00。同行イベントはPM6:00まで。

### 終了時間 または 経過時間

PM6:00、または出し物巡りの完了時。

## 発生条件

4ループ目に小太郎が同行している状態で、客引きを手伝うと発生する。
