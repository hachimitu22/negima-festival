# 配達イベント

## 文書情報

- 仕様状態: 確定
- 実装状況: 実装済み

## 目的

依頼者から受取人へ届け物を運ぶ目的を提示し、人物の探索とマップ移動を促す。

## 関係する用語

- 配達イベント
- 配達タスク
- 差出人
- 受取人
- 実行中イベント

## 開始条件

- 他の継続イベントを実行していない。
- 会話相手が配達依頼の候補として選ばれる。
- 差出人以外の登場人物が1人以上存在する。

依頼時の会話相手を差出人とする。
差出人以外の生徒と教師を含む全登場人物から、受取人をランダムに1人選ぶ。

## 終了条件

- 受取人へ届け物を渡す会話を完了すると成功する。
- 差出人との再確認で断ることを選ぶと失敗する。
- カシオペアを使用すると結果を残さず破棄する。

## ルール

- 配達に時間制限はない。
- 依頼時の会話が完了するまでは実行中イベントとして表示しない。
- 依頼時の会話完了後、配達を実行中として表示する。
- 実行中に差出人と会話すると、配達を続けるか断るかを選べる。
- 受取人との完了会話を終えるまで成功しない。
- 差出人と受取人以外との会話は通常会話として扱い、配達状態を変更しない。
- 配達中は新しい継続イベントを開始しない。
- 成功または失敗した配達は実行中イベントから取り除く。

## 状態遷移

```text
提示 --依頼会話を完了--> 実行中
実行中 --差出人に継続を回答--> 実行中
実行中 --差出人に断ると回答--> 失敗
実行中 --受取人との完了会話を完了--> 成功
実行中 --カシオペアを使用--> 破棄
```

## 好感度

- 成功時、差出人が生徒ならその好感度を5増やす。
- 成功時、受取人が生徒ならその好感度を5増やす。
- 差出人と受取人がともに生徒なら、それぞれに適用する。
- 教師には適用しない。
- 依頼時と再確認時の会話では好感度を変更しない。
- 失敗時は好感度を変更しない。

## 具体例

1. 生徒Aから教師Bへの配達を依頼される。
2. 依頼会話を終えると配達が実行中になる。
3. 教師Bと同じ場所へ移動し、完了会話を終える。
4. 配達は成功し、生徒Aの好感度だけが5増える。
