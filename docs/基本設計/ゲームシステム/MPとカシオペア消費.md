# MPとカシオペア消費

## MP

- MPの最大値は300。
- ゲーム開始時のMPは300。
- ゲーム内時間5分の経過でMPを2回復する。
- MPは最大値を超えない。

## カシオペア

- カシオペアは戻す時間5分につき1MPを消費する。
- 24時間戻す場合の消費量は288MP。
- チュートリアルの自動巻き戻しも同じ消費量計算を使用する。
- チュートリアルのPM8:00からAM9:55への巻き戻しは605分のため121MPを消費する。
- MPが不足している場合、カシオペアは使用できず状態も変更しない。
- 巻き戻し可能な時刻の下限は1日目AM10:00とする。
- チュートリアルスキップ後も、チャオを発見するまでカシオペアは使用できない。
- チャオ発見後にカシオペアの使用を解禁する。
