# マップと登場人物の移動

## 文書情報

- 仕様状態: 確定
- 実装状況: 実装済み

## 目的

プレイヤーと登場人物の現在地、場所同士の接続、時間経過による登場人物の移動を定める。

## 関係する用語

- 場所
- 現在地
- 移動可能先
- 登場人物
- 同伴者

## プレイヤーの移動

- プレイヤーは現在地を1つ持つ。
- 初期位置は体育館前広場とする。
- 現在地から直接つながる移動可能先だけを選択できる。
- 場所を選択すると、プレイヤーの現在地をその場所へ変更する。
- マップには各場所にいる生徒と教師を表示する。

## 登場人物の自動移動

- 登場人物は現在地を1つ持つ。
- ゲーム内時間で3時間から10時間ごとに移動を判定する。
- 移動間隔は1時間単位でランダムに決め、移動判定ごとに次の間隔を再抽選する。
- 現在地と移動可能先からランダムに1つを選ぶ。
- 現在地が選ばれた場合は移動しない。
- 会話シーン中はゲーム時間が停止するため、自動移動も停止する。
- カシオペアで時間を戻した場合は現在地を維持し、戻った時刻から3時間から10時間後に次回移動時刻を再設定する。
- 同行中の同伴者は自動移動を停止し、プレイヤーと一緒に移動する。

## 教師

- 高畑・T・タカミチと源しずなを教師として配置する。
- 両者の初期位置は職員室とする。
- 教師も生徒と同じ間隔と方法で自動移動する。
- 高畑・T・タカミチは女子トイレと更衣室へ移動しない。
- 源しずなの移動先には固有の制限を設けない。

## 他システムとの関係

- 同じ場所にいる登場人物とは[会話](会話.md)を開始できる。
- [同行イベント](../イベント/同行イベント.md)中は、同伴者の位置をプレイヤーの移動先に合わせる。
- [カシオペア](カシオペアシステム.md)では現在地を巻き戻さず、次回移動時刻だけを再設定する。
- マップ上での確認と操作は[メインゲームシーン](../シーン/メインゲームシーン.md)で行う。

## 具体例

- 体育館前広場からは、ホール、体育館アリーナ、休憩所、グラウンドへ移動できる。
- 体育館前広場から図書室へ直接移動することはできない。
- 高畑・T・タカミチがホールにいる場合、移動先の抽選から女子トイレを除外する。
