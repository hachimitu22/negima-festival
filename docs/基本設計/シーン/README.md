# シーン

## 文書情報

- 仕様状態: 確定

## シーンとは

シーンは、目的と遊び方が大きく変わるゲームの進行単位である。
シーンごとに、プレイヤーが確認できる情報、実行できる操作、進行するゲームシステムが異なる。

メニュー、マップ、実行中イベント一覧など、同じ目的のまま切り替えたり同時に確認したりする表示は独立したシーンにしない。

サブゲームは、具体的な目的と遊び方が決まった時点で追加する。

## シーンの流れ

```mermaid
flowchart TB
  Startup["ゲーム起動"] --> Title["タイトル"]
  Title --> Prologue(["プロローグ"])
  Prologue --> Title
  Title --> NewGame(["はじめから"])
  NewGame --> MainGame["メインゲーム"]
  Title --> Continue(["つづきから"])
  Continue --> MainGame
  Title --> Options["オプション"]
  Options --> Title

  MainGame --> StartConversation(["登場人物との会話を開始"])
  StartConversation --> Conversation["会話"]

  Conversation --> CompleteConversation(["会話完了後に復帰"])
  CompleteConversation --> MainGame
```

タイトルでは、プロローグ、はじめから、つづきから、オプションを選べる。
はじめからを選ぶと、新しい麻帆良祭を開始する。
会話を終えると、新しいメインゲームを開始するのではなく、会話前に進めていた同じ麻帆良祭へ戻る。

## シーン仕様に記載する内容

- シーンの目的
- 開始方法
- 確認できる情報
- プレイヤーができること
- 時間、人物、イベントの動き
- 終了条件と次の場面
- 関連するゲームシステムとイベント
- 未決事項

時間、会話、イベントなど複数のシーンに関係するルールは、各ゲームシステムまたはイベント仕様を正本とする。
シーン仕様では、その場面における影響を説明して正本へリンクする。

## 未決事項

- フェス終了後の結果表示を独立したシーンにするか。
- サブゲームに共通する開始方法と終了方法。
