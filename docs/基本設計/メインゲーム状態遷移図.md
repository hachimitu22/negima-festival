# メインゲーム状態遷移図

## 文書情報

- 仕様状態: レビュー用
- 対象: メインゲームシーンの基本設計レベルの状態遷移
- 関連: [メインゲームシーン](シーン/メインゲームシーン.md)、[三日間システム](ゲームシステム/三日間システム.md)、[カシオペアシステム](ゲームシステム/カシオペアシステム.md)、[イベント共通仕様](イベント/README.md)

## 目的

メインゲームシーン内の遊びの流れを、プレイヤーと祭りに参加するアクターの行動、麻帆良祭で起こる出来事で示す。

## メインゲームフロー

```mermaid
flowchart TB
  subgraph Festival["麻帆良祭の開催中"]
    Explore["学園を散策する"]
    Talk["登場人物と会話する"]
    Event["イベントに参加する"]
    Rewind["カシオペアで時間を戻す"]

    Explore -->|話しかける| Talk
    Talk -->|会話を終える| Explore
    Talk -->|イベントに発展する| Event
    Explore -->|特定の時刻・条件で発生する| Event
    Event -->|イベントを終える| Explore
    Event -->|終了後の会話へ続く| Talk
    Event -->|別のイベントへ続く| Event

    Explore -->|カシオペアを使う| Rewind
    Event -->|カシオペアを使う| Rewind
    Rewind -->|戻した時刻から再開する| Explore
  end

  Festival -->|祭の終了時刻を迎える| End["麻帆良祭が終了する"]
```

### メインゲームフローの補足

- 麻帆良祭の舞台を散策すること自体も、遊びの楽しみとする。
- 散策中は時計が進み続ける。会話やイベントには時間が停止する場面があり、停止条件は[三日間システム](ゲームシステム/三日間システム.md)、[会話](ゲームシステム/会話.md)、各イベント仕様を参照する。
- カシオペアの使用条件、戻せる時間、維持する情報と失われる情報は[カシオペアシステム](ゲームシステム/カシオペアシステム.md)を正本とする。
- 個別イベントの詳細状態は各イベント仕様を正本とする。

## アクターの行動フロー

```mermaid
---
config:
  layout: elk
---
flowchart TB
  Schedule{"今の時間帯に予定がある"}
  Planned["予定に沿って行動する"]
  Free["自由に散策し、祭りを楽しむ"]
  React["プレイヤーの働きかけに応じる"]

  Schedule -->|ある| Planned
  Schedule -->|ない| Free
  Planned -->|予定の時間帯が変わる| Schedule
  Free -->|予定の時刻を迎える| Schedule
  Planned -->|話しかけられるなど| React
  Free -->|話しかけられるなど| React
  React -->|対応を終える| Schedule
```

### アクターの行動フローの補足

- 対象は、プレイヤー以外の生徒、教師、祭りを楽しむ来場者とする。
- 個別の反応内容、予定の競合、移動経路は扱わない。
