# メインゲーム状態遷移図

## 文書情報

- 仕様状態: レビュー用
- 対象: メインゲームシーンの基本設計レベルの状態遷移
- 関連: [メインゲームシーン](シーン/メインゲームシーン.md)、[三日間システム](ゲームシステム/三日間システム.md)、[カシオペアシステム](ゲームシステム/カシオペアシステム.md)、[イベント共通仕様](イベント/README.md)

## 目的

メインゲーム中に、探索、会話、イベント進行、カシオペアによる巻き戻し、祭終了がどのように切り替わるかを、プレイヤーと仕様から見える粒度で示す。

実装上のクラス名、System名、snapshot、表示layer、入力モードは扱わない。

## Mermaid

```mermaid
flowchart TB
  Start((開始))
  GameStarted["ゲーム開始"]
  FestivalActive["祭開催中"]
  Exploring["探索中<br/>移動・情報確認・会話相手選択"]
  Conversation["会話中<br/>時間進行とメイン操作を停止"]
  EventActive["イベント進行中<br/>目的の人物・場所へ向かう"]
  Cassiopeia["カシオペア使用<br/>MP消費・最大24時間戻る"]
  Rewound["巻き戻し後の再開<br/>実行中イベントを破棄"]
  FestivalEnded["祭終了"]
  ResultPending["結果表示未決定"]

  Start -->|タイトルでゲーム開始| GameStarted
  GameStarted -->|麻帆良祭が始まる| FestivalActive
  FestivalActive -->|現在地・時間・MP・イベントを確認| Exploring

  Exploring -->|同じ場所の登場人物を選ぶ| Conversation
  Conversation -->|通常会話完了| Exploring
  Conversation -->|イベント開始またはイベント会話完了| EventActive

  Exploring -->|実行中イベントの目的を確認| EventActive
  EventActive -->|達成 / 失敗 / 中断| Exploring

  Exploring -->|MPが足りる状態で使用| Cassiopeia
  EventActive -->|MPが足りる状態で使用| Cassiopeia
  Cassiopeia -->|時間を戻す| Rewound
  Rewound -->|戻った時間から再開| Exploring

  FestivalActive -->|ゲーム時間72到達| FestivalEnded
  FestivalEnded -->|結果表示への流れは未決定| ResultPending
```

## 補足

- 会話中は時間進行、移動、場所訪問、イベントの時間進行を止める。
- カシオペア使用時に維持する情報と破棄する情報は[カシオペアシステム](ゲームシステム/カシオペアシステム.md)を正本とする。
- 個別イベントの詳細状態は各イベント仕様を正本とする。
