# 構想整理

## 目的

この章は、麻帆良祭ゲームとして実現したい体験、ルール、状態の切り方を整理するための基本設計候補である。

既存の基本設計や実装に合わせることを主目的にせず、今後のゲーム全体を発展させるための判断軸を先に明確にする。
整理済みになった内容は、必要に応じて既存の基本設計へ反映する。

## 進め方

- 詳細設計、クラス構造、DOM UI都合は扱わない。
- プレイヤーから見える遊び、ゲーム内概念、ルール、未決事項を優先する。
- 確定事項とアイデアを分けて記録する。
- 図は小規模なものはMermaidの`flowchart`で記述する。

## 操作前提

プレイヤー操作は、キーボード、マウス、ゲームパッドを想定する。
スマホなどのタッチ操作は想定外とする。

この章では、具体的なキー割り当て、ボタン割り当て、DOM UI上の入力部品は扱わない。
操作前提は、麻帆良祭を探索し、会話し、イベントへ対応するためのゲーム体験上の前提として扱う。
