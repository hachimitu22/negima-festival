# ゲーム目的

## 中心体験

プレイヤーはネギとなり、麻帆良祭をクラスメイトと一緒に楽しむ。

クラスメイトの出し物を見に行く、待ち合わせる、祭りを一緒に回る、困り事を手伝うといった交流をゲーム前半の主目的とする。移動中や交流中には別のイベントやハプニングが接続し、その場で取った行動にクラスメイトが反応する。

祭りを楽しむこと、クラスメイトを知ること、物語を進めることを一つの体験として扱う。

## 祭りで行うこと

- クラスメイトと会話し、一緒に麻帆良祭を回る。
- クラスメイトの出し物や麻帆良祭の有名な催しを見る。
- 教師として見回り、トラブル対応、告白阻止を行う。
- 学園都市を探索し、人物、出店、出来事を発見する。
- 武道会や中夜祭など、決まった時刻に行われる大規模イベントへ参加する。
- 地下水路など、祭り会場から外れた場所も探索する。

## 時間巻き戻し

一度の進行ですべての交流とイベントを体験することはできない。

プレイヤーはカシオペアで時間を戻し、前のループで得た時刻、場所、条件、人物への理解を使って別の行動を試す。見逃しや失敗も、次のループで別の結果へ到達するための情報になる。

好感度、主要イベントの達成記録、判明した情報はループを越えて蓄積する。

## 本筋

1日目午前から2日目午後までは、クラスメイトとの交流、武道会、中夜祭を中心に麻帆良祭を楽しむ。

武道会で準優勝し、2日目夜の主要場面へ参加すると、超鈴音の企みを追う本筋が進行する。3日目は企みを阻止するための最終局面となる。

本筋は時刻だけでは進行しない。必要な主要イベントを達成し、該当する場面へ参加することで次の段階へ進む。

原作時系列と進行条件は[メイン進行](主要システム/メイン進行.md)、3日目の進行は[3日目最終局面](3日目最終局面.md)を参照する。

## 最終目的

クラスメイトとの交流、イベント達成、情報収集を積み重ね、超鈴音の企みを阻止する。

それまでの行動は、最終局面で受けられる協力、展開、難易度、演出へ反映する。
