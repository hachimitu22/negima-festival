# ダンジョン探索

## 文書情報

- 対象: 通常探索から派生するダンジョン的な探索コンテンツ

## 目的

麻帆良祭や麻帆良学園を巡る通常探索とは別に、入口を通じて入る寄り道、挑戦、深層攻略型の探索を整理する。

通常探索は、メイン進行の基礎行動として扱う。
ダンジョン探索は、通常探索から派生し、迷路、階層、仕掛け、トラップ、報酬、帰還判断などを強めた探索コンテンツとして扱う。

## 通常探索との関係

通常探索は、麻帆良祭会場や麻帆良学園内を移動し、人物、出し物、イベント、教師仕事へ接触する基本状態である。
詳細は[メイン進行](../主要システム/メイン進行.md)と[マップ](../../ゲームシステム/マップ.md)を参照する。

ダンジョン探索は、通常探索そのものとは同一視しない。
通常探索中に入口を見つける、条件を満たして挑戦できる、または寄り道として入るコンテンツとして扱う。

## 対象コンテンツ

| コンテンツ                                      | 位置づけ                                   |
| ----------------------------------------------- | ------------------------------------------ |
| [地下水路探索](地下水路探索.md)                 | 本編中に入れる軽から中規模の寄り道探索     |
| [図書館島ダンジョン](図書館島ダンジョン.md)     | 高難度、深層攻略、階層内ギミック寄りの探索 |

## 地下水路探索と図書館島ダンジョンの違い

| 項目       | 地下水路探索                       | 図書館島ダンジョン                       |
| ---------- | ---------------------------------- | ---------------------------------------- |
| 解禁時期   | 麻帆良祭中の本編進行               | ストーリークリア後の候補                 |
| 位置づけ   | 通常進行中の寄り道探索             | 高難度の裏ダンジョン                     |
| 規模       | 軽から中規模                       | 深層まで潜る大規模                       |
| 時間       | 外の祭時間が進む                   | 外の祭時間が進む                         |
| カシオペア | 通常進行と同じ扱い                 | 階層内攻略ギミックとして深く使う         |
| 主な体験   | 迷路、近道、裏側の発見、軽い仕掛け | パズル、バトル、トラップ、深層攻略       |

## 基本方針

- 通常探索は、麻帆良祭全体を移動する基礎行動として扱う。
- 地下水路探索と図書館島ダンジョンは、ダンジョン探索カテゴリにまとめる。
- 個別の時間、カシオペア、同行者、失敗、報酬は各ページで扱う。
- ダンジョン探索は、祭り体験や原作追体験の主軸を置き換えない。
