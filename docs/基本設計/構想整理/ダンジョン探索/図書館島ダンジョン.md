# 図書館島ダンジョン

## 目的

図書館島を通常探索のエリアとして扱い、地下へ進む階層型の探索を実装する。

## プロトタイプVer2仕様

- チュートリアル完了後から図書館島へ移動できる。
- 図書館島で「探検する」を選ぶと地下1階から開始する。
- 探索中は「左」「中央」「右」から進行方向を選ぶ。
- 1回の選択で5分経過する。
- 選択結果はランダムに通常通過、トラップ、結界のいずれかになる。
- トラップと結界は1〜5MPを消費する。
- 結界の解除に必要なMPが足りない場合は待機し、5分経過ごとにMPを回復する。
- MPが0になった場合は図書館島へ帰還する。
- 「帰還する」を選ぶと探索を終了する。
- 1日目PM11:30になると麻帆良祭終了演出へ移行する。
- 地下10階に到達すると到達イベント後に帰還する。
- 地下10階到達記録はループ後も保持する。
- 探索を途中で終了した場合、次回は地下1階から開始する。
- 探索中も麻帆良祭のゲーム内時間は進行する。

## 探索結果

通常通過では次の階へ進む。
トラップではMPを消費して次の階へ進む。消費後にMPが0になった場合は帰還する。
結界ではMPを消費して解除し、次の階へ進む。MP不足時は結界を保持したまま待機する。

## 今後の拡張

プロトタイプVer2では階層進行と簡易イベントのみを扱う。パズル、バトル、複雑なトラップ、同行者固有の攻略効果は今後の拡張対象とする。
