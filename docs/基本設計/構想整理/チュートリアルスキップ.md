# チュートリアルスキップ

チュートリアルはスキップできる。

スキップすると、チャオ探索完了後と同じ状態で1日目2ループ目PM2:00の入場門から自由探索へ入る。
カシオペアは起動済みとして扱い、MPは70になる。
チャオは発見済み、説明書は取得済みとして扱う。のどかデート準備をメインイベントに設定する。

スキップはチュートリアル中だけ実行できる。
チュートリアル終了後の自由探索、デート準備では実行できない。

## 操作制限

チュートリアル中の画面は自由探索と同じ場所選択・行動選択で構成する。

チュートリアルの進行に必要な移動先と行動だけを有効にし、それ以外は非活性で表示する。

チュートリアル中は移動中と行動中のハプニングを発生させない。

チャオ探索完了時に現在時刻がPM2:00より前であれば、待機と同じ時間経過処理でPM2:00まで進める。
