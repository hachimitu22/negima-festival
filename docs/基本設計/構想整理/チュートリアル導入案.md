# チュートリアル導入案

## 役割

最初のカシオペア起動までの原作エピソードを使い、麻帆良祭、時間経過、同行者を含む時間移動、過去の自分との同時存在を順番に体験させる。

出来事の原作時系列は[原作の流れ](../../原作の流れ.md)を正本とする。

## 時刻の進行

プレイヤーの操作中は祭り時間を進めない。操作を完了した時点で、次の場面に対応する固定時刻へ切り替える。

| 操作 | 操作中 | 完了後 |
| --- | --- | --- |
| 3-Aまで移動 | AM10:00 | AM10:00 |
| 3-Aお化け屋敷を探索 | AM10:00 | AM11:00 |
| 保健室まで移動 | AM11:00 | AM11:00 |
| 仮眠 | 操作なし | PM8:00 |
| カシオペア自動起動 | 操作なし | AM09:55 |
| カフェまで移動 | AM09:55 | AM10:00 |
| のどかを尾行 | AM10:00 | AM10:00 |
| のどかから隠れる | AM10:00 | AM10:00 |
| エヴァから逃走 | AM10:00 | AM10:00 |

## プロローグ

前日の出来事は文字送りで進める。

1. 学園長が世界樹伝説と6か所の魔力溜まりについて説明する。
2. ネギは魔法先生として、魔力溜まりで行われる告白を阻止する仕事を受ける。
3. クラスメイトの出し物と教師仕事を両立するスケジュールに悩む。
4. 魔法先生たちに追われているチャオを助ける。
5. チャオの行動に責任を持つことを条件に、チャオを解放してもらう。
6. チャオからカシオペアを受け取る。
7. ネギはカシオペアの用途を知らないまま麻帆良祭を迎える。
8. 前夜祭の飛行船で、チャオ、葉加瀬、茶々丸が怪しげな話をする。

プロローグ中の操作は文字送りだけとする。

## 1日目1ループ目

### AM10:00

1. 一般客向けの開演宣言とパレードが始まる。
2. 夕映とのどかが来場者数など、麻帆良祭の規模を説明する。
3. ネギは3-Aクラスのお化け屋敷へ向かう。
4. お化け屋敷を体験する。

パレード会場からお化け屋敷までの移動はプレイヤーが操作する。お化け屋敷では短い屋内マップを移動し、3つの驚かし演出地点を順番に通って出口へ向かう。驚かし演出に失敗条件は設けない。

### AM11:00

1. 徹夜でお化け屋敷の準備を手伝った疲れにより、ネギがふらつく。
2. ネギは保健室で30分仮眠することを決める。
3. カモと刹那が同行して保健室へ向かう。
4. 保健室へ到着すると仮眠に入る。

お化け屋敷から保健室までの移動はプレイヤーが操作する。カモと刹那はネギへ追従する。

### PM8:00

1. ネギ、カモ、刹那が目を覚ます。
2. 予定を大幅に過ぎたことに三人が慌てる。
3. ネギの携帯電話には20:06と表示される。
4. カシオペアが自動的に起動する。
5. ネギ、カモ、刹那が一緒に1日目AM09:55へ移動する。

初回起動はプレイヤーに操作させない。カシオペアは固定で30 MPを消費する。

## 1日目2ループ目

### AM09:55からAM10:00

1. 三人は突然朝へ戻ったことに混乱する。
2. 三人はカフェへ移動する。
3. カフェへ到着するとAM10:00になり、再び開演宣言とパレードが始まる。
4. 三人は2日目ではなく、同じ1日目へ戻った可能性を疑う。

### のどかとの遭遇

1. 三人はカフェで状況を整理する。
2. のどかと鉢合わせるが、のどかは三人を見て不思議そうな反応をする。
3. カモがすぐに戻ると伝え、のどかをカフェから送り出す。
4. 三人はのどかを尾行する。
5. のどかが過去のネギたちのところへ戻る。
6. 三人は過去のネギ、カモ、刹那が同じ時間に存在することを確認する。
7. のどかが振り返るため、三人は物陰へ隠れる。
8. 三人は1日目へタイムスリップしたことを確信する。

尾行では、のどかから3マス以上8マス以内の距離を保つ。3マス未満の状態が1秒続くとのどかに気づかれ、8マスより離れた状態が2秒続くと見失う。失敗時は尾行開始位置から再試行する。

のどかが振り返る3秒前に予兆を表示する。プレイヤーは視線が通らない物陰へ移動する。発見された場合は隠れる場面の開始位置から再試行する。

### エヴァとの遭遇

1. ネギはカシオペアがタイムマシンであることを喜ぶ。
2. 三人はエヴァと鉢合わせる。
3. エヴァに追いかけられる。
4. 三人はエヴァの追跡を振り切る。
5. カシオペアについて聞くため、チャオを探すことを決める。

エヴァから逃げる場面では2秒の先行時間を設ける。ネギは4マス/秒、エヴァは3.6マス/秒で移動する。エヴァとの距離が1マス以下になると捕まり、逃走開始位置から再試行する。逃走地点へ到達すると追跡を振り切る。

チャオを探す目的が提示された時点で導入を終了する。

## 教える内容

- 麻帆良祭は決められた時刻に開演し、催し物と人物が時間に沿って行動する。
- ネギはクラスメイトとの予定と魔法先生の仕事を持つ。
- カシオペアはネギの周囲にいる人物も一緒に過去へ移動させる。
- 時間を戻しても過去のネギたちは消えず、同じ時間に存在する。
- 過去の自分や同行者との遭遇を避ける必要がある。
- カシオペアの用途を知るため、次にチャオを探す。

## 通常進行との接続

導入終了後は、チャオを探すことを最初の主目的として通常進行へ接続する。

カシオペアの任意使用、自由探索、原作の続きは、この導入の後に実装する。
