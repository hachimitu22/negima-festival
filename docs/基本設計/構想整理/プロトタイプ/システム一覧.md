# プロトタイプのシステム一覧

| システム | 責務 | 実装対応 |
| --- | --- | --- |
| プロトタイプ進行 | チュートリアル、自由探索、イベント開始・終了の画面進行を管理する | `CanonicalFestivalPrototypeScene` |
| ゲーム時間 | 祭り日、ループ、時刻を管理し、固定時刻へ進める | `CanonicalFestivalPrototypeScene` |
| MP | 時間経過による回復と魔法・巻き戻しによる消費を管理する | `CanonicalFestivalPrototypeScene` |
| カシオペア | チェックポイントを使って最大24時間の巻き戻しを行う | `CanonicalFestivalPrototypeScene` |
| 場所選択・探索 | エリア移動、移動中、到着後の現地行動を管理する | `CanonicalFestivalPrototypeScene` |
| 図書館島探索 | 図書館島の地下1階から地下10階までの選択式探索、トラップ、結界、MP不足時の待機、帰還を管理する | `CanonicalFestivalPrototypeScene` |
| キャラクター | クラスメイトの位置、状態、ランダム行動を管理する | `CanonicalFestivalPrototypeScene` |
| パーティ | 同行者の加入、解散、移動追従を管理する | `CanonicalFestivalPrototypeScene` |
| 会話 | クラスメイトとの通常会話、聞き込み、固定会話を進める | `CanonicalFestivalPrototypeScene`、`DialogueSystem` |
| 好感度 | クラスメイトとの会話結果を関係値へ反映する | `CanonicalFestivalPrototypeScene` |
| イベント管理 | イベント定義、イベント状態、現在のイベント、イベント固有データを管理する | `CanonicalFestivalPrototypeScene` |
| ハプニング | 移動中・行動中の割り込み、対応、無視を処理する | `CanonicalFestivalPrototypeScene` |
| 主要イベント | ホラーハウス、チャオ探索、のどかデート、まほら武道会、出し物巡りをイベント状態として進行する | `CanonicalFestivalPrototypeScene` |
| スケジュール | ネギ予定、麻帆良祭出店、クラスメイト出し物、完了チェックを提供する | `CanonicalFestivalPrototypeScene` |
| 麻帆良祭通知 | 放送、延期、会場変更、出店の盛り上がり通知を処理する | `CanonicalFestivalPrototypeScene` |
| 麻帆良祭終了・ゲームオーバー | 1日目PM11:30の終了演出とPM11:37のチャオの企み発動を処理する | `CanonicalFestivalPrototypeScene` |
| 出店盛り上がり | チラシ、時間経過、ランダム変動、閾値通知を処理する | `CanonicalFestivalPrototypeScene` |
| 永続記録 | チャオ発見、好感度、CG、イベント完了チェックをループ間で保持する | `CanonicalFestivalPrototypeScene` |

## 責務の境界

- `CanonicalFestivalPrototypeScene`は、プロトタイプのゲームルールと状態遷移を管理する。
- `CanonicalFestivalPrototypeScene`の`events`は主要イベントの定義と状態を管理する。チャオ探索はこのイベント群の一つである。
- `phase`は入力や画面を決める進行段階であり、イベントそのものを表さない。
- `DialogueSystem`は、会話セッションの入力と進行を管理する。
- `GameFlowSystem`は、フレーム更新と入力モードを管理する。
- `TimeControlSystem`は、共通ゲーム時間と時間制御の責務を持つ。
- Viewはスナップショットを表示し、ゲームルールを持たない。
