# プロトタイプのドメイン要素

## プレイヤーとアクター

| 要素 | 説明 |
| --- | --- |
| プレイヤー | ネギを操作し、麻帆良祭の行動を選択する主体 |
| ネギ | プレイヤーキャラクター。移動、会話、イベント、教師仕事を行う |
| アクター | ネギと会話、同行、イベントを行う人物 |
| クラスメイト | アクターのうち、出し物、会話、好感度、聞き込みの対象となる人物 |
| 同行者 | ネギと行動を共にし、移動経路を追従するアクター |
| パーティ | ネギと同行者で構成する行動単位。カモはパーティ人数に含めない |
| カモ | ネギに助言する常駐キャラクター。マップ上のアクターとしては表示しない |

## 時間とループ

| 要素 | 説明 |
| --- | --- |
| 麻帆良祭 | ゲームの舞台となる祭り。ゲーム内時間とイベントの基準となる |
| ゲーム時間 | 麻帆良祭の日付、ループ、時刻で構成する現在時刻 |
| ループ | カシオペアで過去へ戻った後の時間進行単位 |
| カシオペア | 最大24時間まで過去へ戻る道具。戻る時間に応じてMPを消費する |
| MP | 魔法とカシオペアに使用する魔力。ゲーム時間の経過で回復する |
| チェックポイント | カシオペアで指定時刻の状態を復元するための履歴 |

## 場所と探索

| 要素 | 説明 |
| --- | --- |
| エリア | 入場門、校舎、食堂街など、移動先として選択する大きな場所 |
| 場所 | エリア内で行動の対象となる地点または施設 |
| 自由探索 | 現在地から移動先と現地行動を選択するゲーム状態。イベントを開始する前後の進行基盤 |
| 移動 | 現在地から別エリアへ向かう行動。移動中は時間を進めない |
| 現地行動 | 到着したエリアで選択できるイベント、会話、タスク、待機などの行動 |
| ランドマーク | 進行目標や目的地として示される主要地点 |

## イベントと進行

| 要素 | 説明 |
| --- | --- |
| イベント | プレイヤーが体験する一連の出来事。定時、条件、突発、連続進行を含む |
| 主要イベント | 複数の進行段階と専用状態を持つイベント。ホラーハウス、チャオ探索、デート、武道会など |
| ハプニング | 移動中または行動中に割り込む短い出来事 |
| タスク | 迷子対応、教師仕事など、達成条件を持つ作業型イベント |
| エピソード | 複数の場面や選択を連続して進めるイベント |
| 巻き込み | 移動や行動中に別イベントの対応を要求されること |
| 波及 | イベントの影響が別エリアや別イベントへ広がること |
| メインイベント | 複数の受注中イベントからプレイヤーが追跡対象として選ぶイベント |
| 受注中イベント | 発生条件を満たし、現在進行可能なイベント |
| 成功 | イベントの成功条件を満たして終了した状態 |
| 未クリア | ミニゲームなどを完了できずに終了した状態。イベントは失敗として扱う |

### 主要イベント

| イベント | 内容 |
| --- | --- |
| 3-Aホラーハウス | 難易度選択、一本道の探索、パニック、未クリア分岐を持つエピソード |
| チャオ探索 | 聞き込み、候補地点調査、アトラクション、飛行船、チャオ遭遇を順に進めるエピソード |
| のどかとのデート | 準備、時間条件、好感度による結末分岐を持つエピソード |
| まほら武道会 | 通知、会場変更、受付、予選を進めるエピソード |
| クラスメイト出し物巡り | クラスメイトの出し物を順に体験するエピソード |
| 小太郎・あやかとの出し物巡り | ホラーハウスの手伝いから発生する分岐エピソード |
| 夕映との麻帆良祭巡り | のどかデートのキスルート経験後に解放されるエピソード |

## 記録と関係値

| 要素 | 説明 |
| --- | --- |
| スケジュール | 既知の予定、タスク、出店、完了状態を確認する情報 |
| 通知 | 麻帆良祭放送や出店の盛り上がりを知らせる情報 |
| 盛り上がり | 出店やイベントの活性度。一定値で通知を発生させる |
| 好感度 | クラスメイトとの交流で上昇する関係値 |
| CGフラグ | のどかのキスルートなど、取得済み演出を記録する値 |
| 完了チェック | 成功して実施済みとなったスケジュールに表示する記録。ループ後も保持する |

## 要素間の関係

- プレイヤーはネギを操作し、エリアを移動して現地行動を選択する。
- 現地行動によってイベント、会話、タスク、エピソードが進行する。
- 主要イベントはイベント状態として管理し、画面の進行段階とは分離する。
- イベントはゲーム時間、場所、アクター、エリア状態を参照して発生する。
- 移動中や行動中にはハプニングが発生し、現在の行動へ巻き込む。
- カシオペアはチェックポイントを復元してゲーム時間とループを変更する。
- チャオ発見、好感度、CGフラグ、完了チェックなどの永続記録は巻き戻し後も保持する。
