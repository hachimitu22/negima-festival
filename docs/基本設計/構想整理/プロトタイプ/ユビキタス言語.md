# プロトタイプのユビキタス言語

## 基本用語

| 用語 | 定義 |
| --- | --- |
| Canonicalプロトタイプ | 原作導入から自由探索と主要イベントを固定進行で体験するプロトタイプ |
| チュートリアル | 最初のカシオペア起動とエヴァ逃走までの固定進行 |
| 自由探索 | チュートリアル後に場所と現地行動を選ぶ進行 |
| ループ | カシオペアで時間を巻き戻した後の周回。巻き戻しのたびにループ数が増える |
| 巻き戻し | カシオペアで同じ麻帆良祭の過去時刻へ戻ること |
| ゲーム時間 | 麻帆良祭の日、ループ、時刻を表すゲーム内の時刻 |
| 現地行動 | 到着したエリアで実行する行動の総称 |
| 現在地 | ネギが所属している現在のエリア |

## イベント用語

| 用語 | 定義 |
| --- | --- |
| 定時イベント | 決められた時刻と場所で開始できるイベント |
| 条件イベント | 好感度、発見、同行などの条件を満たすと開始できるイベント |
| 突発イベント | 行動中にランダムで割り込むイベント |
| ハプニング | 突発的に発生し、現在の行動へ割り込む短いイベント |
| タスク | 目的地、期限、達成条件を持つ作業型イベント |
| エピソード | 複数の会話や行動を順に進める連続イベント |
| 主要イベント | 専用の状態と複数の進行段階を持つイベント。チャオ探索も主要イベントの一つ |
| 巻き込み | 実行中の行動に別イベントが割り込むこと |
| 波及 | 発生したイベントの影響が別エリアや別イベントへ移ること |
| 分岐 | 条件または選択によってイベントの進行ルートが変わること |
| 未クリア | ミニゲームなどを完了できず、成功記録を残さずに終了した状態 |

## 探索・人物用語

| 用語 | 定義 |
| --- | --- |
| エリア | 移動先として選ぶ大きな区画 |
| 場所 | エリア内の施設または行動地点 |
| アクター | 会話、移動、イベントの対象となる人物 |
| 同行者 | ネギと一緒に行動し、移動経路を追従するアクター |
| パーティ | ネギと同行者の組み合わせ |
| チャオ探索 | 主要イベントの一つ。チャオの居場所を手がかりから探すエピソード |
| 候補地点 | チャオ探索で調査できる場所 |
| 聞き込み | クラスメイトへチャオの情報を質問する行動 |

## 記録・情報用語

| 用語 | 定義 |
| --- | --- |
| 受注中イベント | 発生済みで、現在の進行対象にできるイベント |
| メインイベント | 受注中イベントから選ぶ主な追跡対象 |
| スケジュール | 予定、イベント、タスク、出店の情報を確認する画面情報 |
| 麻帆良祭通知 | 麻帆良祭放送や出店の盛り上がりを知らせる通知 |
| 盛り上がり | 出店の活性度を示す値 |
| 実施済み | イベントを成功させて終了した状態 |
| 完了チェック | 実施済みのスケジュールに付くチェック表示 |
| 永続記録 | ループや巻き戻し後も保持する発見、好感度、CG、完了チェックなどの記録 |
| ループ状態 | 巻き戻し時に復元され、ループごとに作り直される現在の進行状態 |
