# プロトタイプ体験範囲

## 目的

最初のカシオペア起動からチャオ探索完了までの原作エピソードをチュートリアルとして再現し、麻帆良祭の開始、時間経過、同行者を含む時間移動、過去の自分との同時存在、チャオ探索を一続きに体験できることを確認する。

チュートリアル完了後は場所選択式の自由探索へ接続し、イベントの発生、成長、波及、合体、巻き込みを検証する。

出来事の原作時系列は[原作の流れ](../../原作の流れ.md)を正本とする。

## 対象範囲

- 開始: 麻帆良祭前日のプロローグ
- プレイ開始: 1日目1ループ目AM10:00
- 初回巻き戻し: 1日目PM8:00から1日目AM09:55
- チュートリアル終了: 飛行船でチャオを発見した時点
- チュートリアル操作: 自由探索と同じ場所選択、行動選択、文字送り、ホラーハウスのコース選択と探索、のどかの尾行、過去ネギから身を隠す操作、エヴァから逃げる操作、チャオの聞き込み、候補地点の調査
- 自由探索検証: PM2:00以降の場所選択、到着後行動、イベント巻き込み判断
- まほら武道会検証: PM5:00の延期通知、グラウンドの小太郎合流、龍宮神社への会場変更、受付、攻撃・投げ・防御による予選、PM8:00から通常探索への復帰
- 図書館島検証: 図書館島への移動、地下1階から地下10階までの選択式探索、トラップ・結界・MP不足時の待機、帰還
- 麻帆良祭終了検証: 1日目PM11:30の終了演出、PM11:37のチャオの企み発動、ゲームオーバー

## 体験の流れ

### プロローグ

1. 世界樹の魔力溜まりと告白阻止の仕事を知る。
2. ネギがチャオを助け、用途を知らないままカシオペアを受け取る。
3. 前夜祭でチャオ、葉加瀬、茶々丸が怪しげな話をする。

### 1日目1ループ目

1. AM10:00に開演宣言とパレードが始まる。
2. 夕映とのどかから麻帆良祭の説明を聞く。
3. 3-Aクラスのホラーハウスへ移動し、原作再現として難しいコースを体験する。
4. AM11:00にカモ、刹那と保健室へ移動する。
5. 30分の予定で仮眠する。
6. PM8:00に目覚めるがカシオペアが自動起動し、三人でAM09:55へ戻る。

### 1日目2ループ目

1. 何が起こったのか混乱しているがネギの携帯電話は20:06を表示していることを確認する。
2. AM10:00に開演宣言とパレードが再び始まる。
3. カフェで状況を整理しているとのどかに出会う。
4. のどかを尾行し、過去のネギを確認する。
5. のどかに見つからないよう物陰へ隠れる。
6. 三人が1日目へタイムスリップしたことを確信する。
7. エヴァと鉢合わせし、追跡を振り切る。
8. カシオペアについて聞くため、チャオを探すことを決める。
9. チャオを探す目的を最初の主目的候補として、入場門から場所選択式の自由探索へ入る。

### チュートリアル完了後の自由探索

1. プレイヤーは現在地から移動可能な場所を選ぶ。
2. 選択したエリアへ即時に到着する。
3. 到着時にゲーム内時間を5分進める。
4. 到着後は、その場所で行えることリストを表示する。
5. 行動リストから選んだ行動の実行中に、ランダムまたは条件付きで別イベントが割り込む。

チャオ探索、のどかデート、武道会予選、クラスメイトの出し物巡りなどの原作再現は、自由探索中に選べる主要イベントとして扱う。
好きなキャラとのイベント、教師仕事、出店利用、祭り探索も同じ自由探索の行動候補として扱う。

図書館島では、現地行動の「探検する」から地下探索へ移行する。探索中は左右中央の選択肢で進み、地下10階到達または帰還条件成立で図書館島エリアへ戻る。

## 操作範囲

### 文字送り

- 前日のプロローグ
- 開演パレードと麻帆良祭の説明
- お化け屋敷の体験
- 保健室での仮眠
- PM8:00の起床とカシオペア起動
- カフェでの状況整理
- タイムスリップの確信
- チャオを探す決定

### 移動

- パレード会場から3-Aクラスのお化け屋敷まで
- お化け屋敷から保健室まで
- カシオペア起動地点からカフェまで
- のどかの尾行
- エヴァの追跡から逃げる場面

プロローグからエヴァ逃走までは固定進行とする。チャオ探索は、グラウンドへの移動、ジェットコースター、ガンシューティング、クラブ棟への移動、飛行船でのチャオ発見の順に進む。この間は指定された操作以外の移動、行動、アクターとの会話を禁止する。飛行船でチャオを発見した時点でチュートリアルを終了し、自由探索へ移行する。

### お化け屋敷

3-Aホラーハウスは教室内の短い探索マップとして扱う。プレイヤーは簡単、普通、難しいの3コースから選ぶ。

初回の原作再現では、原作の恐怖度選択に合わせて難しいコースを選ぶ。

教室前側の2つの扉を1つずつ入口と出口に使う。
通路は分岐しない一本道にする。
一本道には曲がり角を置き、入口から出口まで直線的に見通せない構造にする。

教室内は辛うじて先が見える程度の暗さにする。
難易度ごとに視界の狭さ、驚かし演出の密度、パニックメーター上昇量を変える。

ネギが動かずにいる間はパニックメーターが少しずつ下がる。

パニックメーターが最大になると、ネギがパニックを起こしてゴールまで走り抜ける。この場合はミニゲーム未クリアとして記録する。

パニックを起こさず出口へ到達した場合はミニゲームクリアとして記録する。

クリア、未クリアのどちらでもAM11:00に保健室へ向かう原作進行へ合流する。未クリアのコースは後で再チャレンジできる。

### のどかの尾行

のどかは固定経路を移動する。プレイヤーは3マス以上8マス以内の距離を保って追う。

- 3マス未満の状態が1秒続くと、のどかに気づかれる。
- 8マスより離れた状態が2秒続くと、のどかを見失う。
- 失敗時は尾行開始位置から再試行する。

### のどかから隠れる

のどかの振り返りはカットシーンとして扱う。
プレイヤー操作は行わず、ネギたちは自動で物陰へ隠れる。
カットシーン後に、タイムスリップを確信する場面へ進む。

### エヴァからの逃走

逃走開始時に2秒の先行時間を設ける。
ネギの移動速度は4マス/秒、エヴァは3.6マス/秒とする。
逃走地点へ到達すると逃げ切りルートへ進む。
エヴァとの距離が1マス以下になると捕獲ルートへ進む。
どちらのルートでも、チャオを探す目的が提示され、場所選択式の自由探索へ移行する。

### 場所選択式の自由探索

チュートリアル完了後は、自由移動マップではなく場所選択式で自由探索を検証する。
目的は移動操作の手触りではなく、行動中にイベントへ巻き込まれる体験を確認することである。

プレイヤーは現在地の行動リストから行動を選ぶ。
行動リストには別の場所へ移動する行動も含める。
場所移動を選ぶと、選択したエリアへ即時に到着する。
場所間の接続関係とエリア移動の経路候補は[プロトタイプ用マップ](./プロトタイプ用マップ.md)に定義する。
到着後も、その場所の行動リストを表示する。
行動リストには、原作再現、キャライベント、教師仕事、出店利用、聞き込み、周辺確認、場所移動を出せる。
画面上では現在地で行うものを「行動」、別の場所へ向かうものを「移動」として分けて表示する。
行動を選んだ後も、行動完了までの間に別イベントが割り込むことがある。

場所選択式viewでは、現在地、移動先一覧、エリア状態、到着後の行動リスト、行動中の巻き込み判断を表示する。
歩行、通路、視界、連続座標、障害物表現は主目的にしない。

### チャオ探索

チャオ探索は、エヴァ逃走後から開始するチュートリアルの主目的として提示する。グラウンド、ジェットコースター、ガンシューティング、クラブ棟、飛行船の順に進み、飛行船でチャオを発見した時点で終了する。

チャオ探索では、ジェットコースター、ガンシューティング、飛行船の順に進む。正解地点は飛行船に固定する。次の目的地があるエリアへの移動と、次の出し物の調査だけを有効にする。
調査中には、別の祭りイベントやハプニングが割り込むことがある。

チャオ探索中の最初の現在地は入場門とする。
入場門では12:00までパレードが発生しており、現地行動として見ることができる。

チャオ探索中は、現在地の行動リストからエリア移動を選ぶ。
エリアへ到着すると、そのエリアの行動リストを表示する。
チャオ探索中は、現在地で通常表示される行動と移動先を一覧に残す。ジェットコースター、ガンシューティング、飛行船の順序を変える行動、待機、移動先は非活性にし、選択できない状態で表示する。

### 原作再現とキャライベント

のどかデート、武道会予選、クラスメイトの出し物巡りなどの原作再現は、自由探索中に選べる主要イベントとして扱う。
好きなキャラとのイベントも、場所と時刻と人物状態に応じて行動リストへ出す。
どちらも固定一本道ではなく、行動中巻き込みの影響を受ける。

のどかデート準備も、現在地の行動リストから選ぶ。
木乃香への相談、待ち合わせ準備、祭り見物、別場所への移動、約束の時間まで待つ行動を、現在地と進行状態に応じて表示する。
待機は5分刻みで1日目PM23:30まで指定できる。待機専用のデートスキップは用意しない。
のどかデートは、PM4:00からPM5:30の間に食堂街でのどかへ話しかけた場合だけ開始する。

クラスメイトの出し物巡りでは、スケジュール帳に出し物の時刻とエリアを表示する。
プレイヤーはスケジュールを見て行き先を決め、先にエリアへ移動してから、そのエリアで行える出し物を選ぶ。
出し物を直接選んで瞬間的に訪問する形式にはしない。
チャオ探索中に見た出し物は訪問済みとして記録し、後のクラスメイト出し物巡りにも引き継ぐ。

| エリア | 出し物 |
| --- | --- |
| ホール | 3-Aホラーハウス、占い研究会、哲学研究会 |
| クラブ棟 | 美術部、天文学部 |
| 屋台通り | 即席似顔絵、たこ焼き屋 |
| 食堂街 | 料理研究会 |
| グラウンド | 中国武術研究会 |

### クラスメイトの行動予定

クラスメイトは各自の予定表を持つ。
予定は、その人物がその時刻に向かおうとする目的であり、到着を保証する拘束ではない。

予定時間前のクラスメイトは自由に行動する。
自由行動は、次の予定に必ず間に合う範囲へ制限しない。
予定時間が近づくと本人は予定場所へ向かうが、移動距離、混雑、寄り道、イベント巻き込みによって予定に間に合わない場合がある。
予定時刻になっても瞬間移動はしない。

画面外のクラスメイトは、厳密な座標1体として常時管理しない。
画面外では、予定中、自由行動中、行動中、巻き込まれ中などの抽象状態で扱う。
同一クラスメイトが画面外の複数予定や候補状態に存在しても、画面内に同時表示されない限り許容する。
画面内へ表示する時点で、そのクラスメイトの現在表示位置を1つに解決する。

同じ画面内、同じ会話、同じイベント参加中では、同一クラスメイトを2人表示しない。
同一人物が複数いること自体が意味を持つ過去ループ遭遇だけは例外として扱う。

予定時刻に本人が未到着なら、その場に本人はいない。
イベントは、本人不在、遅刻待ち、代役で開始、途中参加のいずれかで進む。
どの扱いになるかはイベント側の性質で決める。
本筋に必要な原作既定進行は、プレイヤー体験とは別に成立する。

クラスメイトの予定や出し物は、場所選択式の行動候補として扱う。
このプロトタイプでは、自由行動、巻き込み、画面内解決により遅刻、不在、途中参加を表現する余地を持たせる。

## カシオペア

- 初回起動はシナリオによる自動起動とする。
- プレイヤーは戻る時刻を選択しない。
- ネギ、カモ、刹那を一緒にAM09:55へ移動させる。
- 初回起動時に固定で30 MPを消費する。
- 携帯電話の時刻は20:06のまま残し、外部の時刻との違いを示す。
- チャオ発見後は自由探索中にカシオペアを使える。
- カシオペアは最大24時間、当日00:00を下限として5分刻みで巻き戻す。
- 消費MPは戻す時間を60分で割って切り上げる。

## 時限人物イベント

時限人物イベントは、時刻、エリア、人物会話の3条件を満たした場合だけ進行する。

のどかデートは、1日目2ループ目PM4:00からPM5:30の間に食堂街でのどかへ話しかけると開始する。
PM5:30を過ぎると、のどかデートは開始できない。

のどかデートをキスルートまで完了すると、次のループ以降に夕映との麻帆良祭巡りを解放する。夕映イベントはPM4:30からPM6:00まで食堂街で開始でき、夕映へ話しかけると進行する。イベント中は夕映が同行し、PM6:00に自由探索へ戻る。

あやかとの出し物巡りは、客引きの手伝いイベント内の分岐ルートとして扱う。小太郎が同行している状態で客引きを手伝うとあやかルートへ進み、イベント開始時刻からPM6:00まで続く。小太郎が同行していない場合は客引きだけで終了する。経験済みフラグはループをまたいで保持する。

あやかルートは、初めからスケジュールに表示しない。小太郎が同行していない状態で客引きの手伝いを実施した場合に、あやかルートをスケジュールへ追加する。追加後は人物名とイベント名を「???」で表示し、発生条件だけを表示する。小太郎が同行している状態で客引きの手伝いを実施した場合は、あやかルートを正式名称で表示する。正式名称の表示状態はループをまたいで保持する。

パーティは、話しかけたアクターが加入可能な場合に加入または辞退を選択できる。武道会などのイベントでは、進行上必要なアクターが強制的に同行する。小太郎は武道会関連の会話、または自由探索中に小太郎へ話しかけることでパーティへ加入できる。同行者はネギの移動経路を追従する。

小太郎はクラスメイト共通アクターとして扱う。クラスメイトステータス、好感度、自由探索中の配置、通常会話、チャオ探索の聞き込み対象に含める。小太郎との会話では通常会話とチャオについて聞く選択肢に加え、パーティへの加入または辞退を選択できる。

## 失敗と再試行

尾行中にのどかへ気づかれた場合または見失った場合は、尾行場面の開始位置から再試行する。

のどかが振り返る場面はカットシーン扱いのため、失敗と再試行を行わない。

エヴァに捕まった場合は捕獲ルートとして進行し、追跡場面の再試行は行わない。

再試行ではゲーム内時刻、MP、完了済みの場面を巻き戻さない。

## 成功条件

- 原作の出来事が正しい時刻と順序で進む。
- 麻帆良祭がAM10:00に開演することが分かる。
- ネギが寝過ごし、カシオペアによってAM09:55へ戻る流れを理解できる。
- ネギ、カモ、刹那が一緒に過去へ戻ったことが分かる。
- 過去のネギたちが同じ時間に存在する危険を理解できる。
- カシオペアがタイムマシンであると確信する過程を理解できる。
- チュートリアル完了後に場所選択式の自由探索へ接続できる。
- 行動中に別イベントへ巻き込まれる体験を検証できる。

## 対象外

- チュートリアル中の任意カシオペア使用
- 自由移動マップによる探索
- 明日菜との待ち合わせ
- 武道会の専用ミニゲーム
- 武道会本戦以降
- 地下水路探索
- 図書館島ダンジョン
- 3日目最終局面
- 最終的な3D表現
- 最終的な画面デザインと演出品質

## 場所選択式自由探索の時間と出し物

チュートリアル中のチャオ探索とチュートリアル完了後の自由探索では、移動または行動を完了するたびに祭り時間を5分進める。チュートリアル中はハプニングを発生させない。
移動先を選択した時点で5分進める。

クラスメイトの出し物は、スケジュール時間内に該当エリアへ行った場合だけ見ることができる。
時間外に同じエリアへ行っても出し物は見られない。
時間外のクラスメイトは通常会話の相手として扱い、出し物を見た記録にはしない。

クラスメイトはスケジュール時間になると予定エリアへ移動し、出し物を行う。
スケジュール時間外はランダムなエリアにいる。
移動先を選択した時点で、時間外の各クラスメイトは5%の確率で現在地以外のランダムなエリアへ移動する。
チャオはこのランダム配置の対象に含めない。

## スケジュール区分

スケジュールはネギのスケジュールと麻帆良祭スケジュールに分ける。

ネギのスケジュールは、クラスメイトの出し物、ネギの仕事、のどかとのデート、世界樹パトロール、格闘大会予選の時刻、エリア、完了状態を扱う。3-Aホラーハウスのチラシ配りをAM10:00からAM11:30までの場所指定なしの予定として登録する。3-Aホラーハウスの客引きの手伝いをAM11:30からPM12:00までの予定として登録する。PM3:00からPM4:00までとPM7:00からPM9:00まで世界樹パトロールを登録する。のどかとのデートをPM4:00からPM5:30まで、格闘大会予選をPM5:30からPM7:00までの予定として登録する。デートとあやかとの出し物巡りは出し物巡りの対象には含めない。
麻帆良祭スケジュールは、祭りの出店の営業時間を扱う。3-Aホラーハウス、ガンシューティング、ジェットコースターをAM10:00からPM4:00までの終日営業として登録する。

麻帆良祭スケジュールは、麻帆良祭内の出店や催し物の時刻、エリア、盛り上がりを扱う。プロトタイプでは3-Aホラーハウス、ガンシューティング、ジェットコースターを登録する。3つとも終日出店として扱い、現在のプロトタイプ範囲ではAM10:00からPM4:00まで表示する。

チラシ配りは全ループで実施できる。1回選ぶごとに5分経過し、ホラーハウスの盛り上がりが10上昇する。小太郎の同行状態に関係なく、チラシ配りはチラシ配りの結果で終了する。客引きの手伝いは、時刻とエリアの条件を満たしている場合に実行できる。客引きの手伝いから、小太郎の同行状態に応じて通常終了またはあやかルートへ分岐する。麻帆良祭スケジュールにはホラーハウス、ガンシューティング、ジェットコースターの盛り上がりを表示する。初期値はそれぞれ0、30、30とする。ガンシューティングとジェットコースターは5分経過ごとにランダムで5上下し、0から100に制限する。3つの盛り上がりはループを巻き戻しても維持する。チラシ配りの完了状態は記録しない。

## チャオ発見後の探索行動

チャオを見つけた後は、チャオの手がかりを探す行動を現在地の行動一覧へ表示しない。

チャオ候補地点の訪問済み状態と発見済み状態は残す。ジェットコースターとガンシューティングを完了すると飛行船へ移動し、飛行船でチャオを発見する。プレイヤーには次の目的として、のどかデート準備や自由行動を選ばせる。
## スケジュール完了表示

スケジュールに掲載されたイベントは、成功して実施を終えるとチェックを表示する。失敗または未クリアで終了した場合はチェックしない。チェック状態はカシオペアによる巻き戻し後も保持する。
