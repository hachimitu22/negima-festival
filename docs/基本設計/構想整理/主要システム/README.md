# 主要システム

## 概要

麻帆良祭ゲームとして主要なゲームシステムを整理する。

このフォルダでは、複数の遊びにまたがって使う共通基盤と、独立した主要システムを扱う。
教師仕事、武道会、ダンジョン探索などは、主要システムを使って成立する個別コンテンツとして構想整理配下の各文書を正本とする。

## 構想整理内の他文書との関係

- [Canonicalプロトタイプ整理](../プロトタイプ/README.md)は、現在実装されているプロトタイプのドメイン要素、用語、システム対応をまとめる。

主要システムは、ゲーム全体を構成する仕組みである。

- [ゲーム目的](../ゲーム目的.md)は、ゲーム全体の体験目的と長期目的を扱う。
- [3日目最終局面](../3日目最終局面.md)は、終盤の固定進行を扱う。
- [教師仕事](../教師仕事.md)、[武道会](../武道会.md)、[ダンジョン探索](../ダンジョン探索/README.md)は、主要システムを使う個別コンテンツとして扱う。
- [取扱説明書](../取扱説明書.md)は、プレイヤー向けに基本的な遊び方だけを説明する。
