# イベントシステム

## 目的

このフォルダでは、麻帆良祭で起こるイベントの発生、成長、波及、予定行動への巻き込み、巻き戻しによる再挑戦を整理する。

個別イベントの仕様ではなく、イベント全体に共通する設計方針を扱う。
本ゲームの一番の売りである「麻帆良祭のわちゃわちゃ感」と、クラスメイトと祭りを一緒に体験する楽しさを作る中心システムとして扱う。

## 全体像

イベントシステムは、クラスメイトとの待ち合わせ、同行、出し物、有名な催し、教師仕事へ向かう途中と実行中に、別の出来事へ巻き込まれる感覚を作る仕組みである。
イベントは単独で発生して終わるだけではなく、場所の盛り上がりや混雑を変え、周辺エリア、人物、噂、別イベントへ影響する。

ハプニングは単独の作業として消化させない。同行中のクラスメイトの反応、会話、提案、好感度、次のイベントを変え、誰と体験したかによって同じ出来事の意味を変える。

プレイヤーは一度のループですべてのイベントを拾いきれない。
見逃し、途中参加、失敗、後から聞く噂も、次のループで試したくなる手掛かりとして扱う。

イベントシステムでは、次の観点を分けて整理する。

- 発生: イベントがいつ、どこで、なぜ起きるか。
- 体験分類: プレイヤーがタスク、ハプニング、エピソードのどれとして体験するか。
- 巻き込み頻度: 予定行動を保ちながら予定外の出来事へ接続できるか。
- 成長: 小さな出来事が人だかり、騒動、大きな催しへ育つか。
- 波及: 場所、人流、人物、噂によって別の場所へ伝わるか。
- エリア状態: イベント発生後に、エリアへ盛り上がり、混雑、注目度、トラブル度などの状態変化が残るか。
- ループ間変化: 前ループの経験によって、次ループの展開可能性が変わるか。

[カモ君助言](../カモ君助言.md)は、イベントシステムが持つ周辺イベント、エリア状態、体験済み定時イベント、失敗から得た情報をプレイヤーへ伝える窓口として扱う。

## 目指す体験

プレイヤーには、次のような感触を与える。

- 気になる出来事が複数あり、今はどれを追うか迷う。
- 解決できなかった出来事も、次のループで先回りしたくなる。
- 自分が見ていない場所でも何かが進んでいると感じる。
- 気づいたら大きくなったイベントが、自分のいる場所へ伝わってくる。
- 同じ時刻、同じ場所でも、過去の経験によって違う広がり方をする。
- はっきりした目的地へ向かっていたはずが、道中の出来事によって予定外の体験へつながる。
- 同じ出来事でも、一緒にいるクラスメイトによって反応と過ごし方が変わる。
- クラスメイトと何を体験したかが記憶に残り、別の人物とも祭りを回りたくなる。
