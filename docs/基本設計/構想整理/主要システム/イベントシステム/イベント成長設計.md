# イベント成長設計

## 文書情報

- 対象: 小さなイベントが大きな出来事へ育つ仕組み

## 目的

麻帆良祭で起きる出来事が、その場限りで終わらず、状況に応じて大きくなっていく感覚を作る。

## 基本方針

ほぼすべてのイベントは、成長の候補になり得る。
ただし、毎回すべてのイベントが大規模化すると祭り全体が読みにくくなるため、成長しやすさ、成長条件、成長方向をイベントごとに持たせる。

成長は、プレイヤーが介入しなくても起こり得る。
ただし、プレイヤーが介入すると、成長先、結果、合流先が変化する。

ランダム突発イベントも成長候補に含める。
重要な突発イベントが偶然発生し、そこから中規模や大規模の出来事へ育つことは、祭りのレアな盛り上がりとして扱う。
ただし、ランダム突発イベントは次ループで同じ発生を再現しない。
前ループでの経験済み記録は、成長先、合流先、発生補助の解禁として扱う。

## 成長段階

イベントは、次のような段階を持てる。

| 段階 | 内容 |
| --- | --- |
| 小規模 | 少人数、短時間、その場だけの出来事 |
| 中規模 | 人だかり、噂、周辺エリアへの影響が出る出来事 |
| 大規模 | 複数エリア、複数人物、別イベントを巻き込む出来事 |

例:

```text
屋台の小トラブル
→ 人だかり
→ 通路の混雑
→ 迷子や落とし物が発生
→ 教師仕事やクラスメイトイベントと合流
```

## 成長条件

成長条件には、次のようなものを使う。

- 時間経過
- エリア状態の変化
- 周辺イベントの存在
- 人物の関心
- プレイヤーの介入または放置
- 前ループでの経験済み記録

放置した結果として大きくなるイベントもあれば、介入した結果としてより良い形で大きくなるイベントもある。

## 成長方向

イベントの成長方向は固定しない。

- 盛り上がり方向: 出し物、観客、パフォーマンスとして大きくなる。
- トラブル方向: 混雑、事故、迷子、教師仕事として大きくなる。
- 人物方向: クラスメイト、教師、来場者の反応へ広がる。
- 噂方向: 後から別の場所で話題になる。

同じイベントでも、プレイヤーの介入やループ間記録によって成長方向が変わってよい。

## 合体との関係

成長したイベントは、近い時間、場所、人物、目的を持つ別イベントと合体しやすくなる。

例:

- ステージ発表の盛り上がりとコスプレ大会が合体する。
- 屋台トラブルと混雑整理が合体し、教師仕事の大きなイベントになる。
- 武道会の活躍が噂になり、翌日の取材イベントへつながる。

合体の詳細は[イベント波及設計](イベント波及設計.md)と[エリア状態設計](エリア状態設計.md)を参照する。
