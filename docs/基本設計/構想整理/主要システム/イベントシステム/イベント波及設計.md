# イベント波及設計

## 文書情報

- 対象: イベントが別の場所、人物、噂へ伝わる仕組み

## 目的

プレイヤーが直接見ていないイベントでも、気づいたら大きくなって自分のいる場所まで伝わってくる感覚を作る。

## 基本方針

イベントの波及は、場所と人流、人物関係と噂の両方で扱う。

場所だけで伝わると機械的になり、人物だけで伝わると会場全体の動きが弱くなる。
そのため、エリアのつながり、観客の移動、クラスメイトや教師の関心、噂話を組み合わせる。

## 波及経路

### エリア波及

隣接エリア、通路、同じ会場内の近い場所へイベントの影響が広がる。

例:

- ライブ会場の歓声が周辺広場へ伝わる。
- 屋台通りの混雑が通路へ広がる。
- 武道会会場の人流が周辺の出し物へ流れる。

### 人流波及

人が動くことで、盛り上がり、混雑、噂、トラブルが別エリアへ移動する。

例:

- 人気イベントの終了後に観客が屋台通りへ流れる。
- 人だかりを避けた来場者が別の道へ流れ、別の混雑を生む。
- 大きな騒動を見た人が別エリアで話題にする。

### 人物波及

クラスメイト、教師、ネームドキャラクターの関心や行動によってイベントが広がる。

例:

- 武道会で活躍すると、取材や噂イベントが発生する。
- 情報に敏感な人物が、別イベントの手掛かりを伝える。
- 特定人物が別の場所へ移動し、そこで派生イベントを起こす。

### 噂波及

会話、掲示、通行人の反応でイベントの情報が伝わる。

例:

- 「向こうで大きな人だかりができている」と聞く。
- 「昨日の武道会の話題で持ちきり」と言われる。
- 「あの出し物が人気らしい」と噂になる。

噂は、プレイヤーを別エリアへ誘導する役割も持つ。

## 合体

波及したイベントは、別イベントと合体することがある。

合体条件には、次のようなものを使う。

- 近い場所で起きている。
- 近い時間帯で起きている。
- 同じ人物または関係人物が関わっている。
- 盛り上がり、混雑、トラブル度が一定以上ある。
- 前ループの経験によって合体先が解禁されている。

合体後のイベントは、元イベントの要素を引き継ぎつつ、より大きな出来事として扱う。

## プレイヤー介入

プレイヤーが介入しなくても、波及は進む。
ただし、プレイヤーが関わることで、次のような変化が起こる。

- 波及先が変わる。
- 合体するイベントが変わる。
- トラブル方向ではなく盛り上がり方向へ変わる。
- 関係人物の反応が変わる。
- 次ループで追える手掛かりが増える。
