# イベント設計方針

## 文書情報

- 対象: 麻帆良祭のわちゃわちゃ感を作るイベント設計の基本方針

## 目的

本ゲームの一番の売りは、クラスメイトと麻帆良祭を回り、次々と出来事へ巻き込まれる体験である。
イベントは単なる目的リストではなく、祭り会場全体が動き、同行者との体験が変化する中心システムとして扱う。

## 基本方針

イベントは会場の各所で発生し、成長し、合体し、人流や通路を通じて別の場所へ波及する。プレイヤーはクラスメイトとの約束や同行、クラスメイトの出し物、有名な催し、教師仕事を主目的として一つ選び、その移動中や実行中に別の出来事へ巻き込まれる。出店と発見地点は、主目的へ向かう道中で選ぶ寄り道として扱う。

プロトタイプでは、自由移動マップではなく場所選択式でこの体験を検証する。
場所を選んだ直後に到着させず、移動中フェーズで通過エリア、混雑、人流、発生中イベント、ランダム突発イベントを処理する。
到着後はその場所で行えることリストを表示し、選んだ行動の実行中にも別イベントが割り込む。

ハプニングへ対応した結果は、時間や場所の状態だけでなく、同行者の台詞、提案、好感度、イベント結果へ反映する。イベントの成長や波及も、プレイヤーまたは同行者の次の行動を変化させて初めて体験上の意味を持つ。

プレイヤーはすべてのイベントを一度に拾いきれない。
見逃し、途中参加、失敗、後から聞く噂も、次のループで試したくなる手掛かりとして扱う。

## 設計の柱

イベント設計では、次の柱を重視する。

- 巻き込み: 予定していた行動へ別の出来事が接続する。
- 移動中: 目的地へ向かう途中で出来事に巻き込まれる。
- 行動中: 到着後に選んだ行動の実行中に別イベントが割り込む。
- 成長: 小さな出来事が、人だかり、騒動、大きな催しへ育つ。
- 合体: 近い時間、場所、人物、目的を持つイベント同士が一つの大きな出来事になる。
- 波及: エリア、人流、人物関係、噂によって出来事が別の場所へ伝わる。
- ループ変化: 同じイベントでも、前ループで得た知識や経験済み記録によって広がり方が変わる。
- 人物反応: 同行者の性格と関係によって、出来事への反応と次の行動が変わる。

## イベント設計の整理軸

個別イベントを考えるときは、次の軸で整理する。

| 軸 | 内容 |
| --- | --- |
| 発生条件 | いつ、どこで、なぜ発生するか |
| 体験分類 | タスク、ハプニング、エピソードのどれに近いか |
| 巻き込み | 軽微、中程度、重大のどの強度で現在行動へ接続するか |
| 成長 | 小規模から中規模、大規模へ育つ余地があるか |
| 合体 | 他イベントと一体化できるか |
| 波及 | エリア、人流、人物、噂で広がるか |
| ループ間変化 | 前ループの経験によって展開可能性が変わるか |
| 人物反応 | 同行者の台詞、提案、好感度、分岐ルートがどう変わるか |

## プレイヤー体験

プレイヤーには、次のような感触を与える。

- 気になる出来事が複数あり、今はどれを追うか迷う。
- 解決できなかった出来事も、次のループで先回りしたくなる。
- 自分が見ていない場所でも何かが進んでいると感じる。
- 気づいたら大きくなったイベントが、自分のいる場所へ伝わってくる。
- 同じ時刻、同じ場所でも、過去の経験によって違う広がり方をする。
- 一緒にいるクラスメイトの反応によって、同じ出来事を別の体験として楽しめる。
