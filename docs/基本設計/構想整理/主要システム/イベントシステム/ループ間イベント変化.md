# ループ間イベント変化

## 文書情報

- 対象: ループをまたいでイベントの展開可能性が変化する仕組み

## 目的

同じ三日間を繰り返しても、プレイヤーの知識や経験によってイベントの広がり方が変わるようにする。

## 基本方針

カシオペアで時間を戻すとループ回数が増え、そのループ内の出来事は巻き戻る。
一方で、プレイヤーが知った情報、経験済み記録、実績、解禁された展開可能性は維持される。

これにより、同じ固定イベントでも、1ループ目と2ループ目以降で広がり方が変わる。

原作再現に関わる主要イベントは、プレイヤーがそのループで実施しなくても、原作上の既定結果として進行する。
クラスメイトとの約束、クラスメイトの出し物、武道会などは、プレイヤーが別行動を選んだ場合でも、後続の本筋や周辺イベントに必要な結果を成立させる。
プレイヤーが実際に参加したかどうかは、体験記録、報酬、好感度、会話差分、実績に反映する。

ランダム突発イベントは例外的に、発生そのものをループ間で再現しない。
軽い出来事でも重要な出来事でも毎ループ抽選し、経験済み記録は発生保証ではなく、発生補助、噂、ヒント、派生可能性として扱う。

## 結果の種類

イベント結果は次の2種類に分ける。

- 既定進行結果: 原作再現や本筋時系列を成立させるために、時間到達や章進行によって確定する結果。
- プレイヤー体験結果: プレイヤーが実際に参加、観戦、会話、介入したことで得る結果。

既定進行結果は、後続イベントの発生条件として扱う。
プレイヤー体験結果は、スケジュール帳の体験済み記録、好感度、報酬、会話差分、実績、追加ヒントの条件として扱う。

未実施のイベントが既定進行結果として成立しても、プレイヤーがその内容を体験済みになるわけではない。
体験済み記録は、プレイヤーがその場に行き、イベントを見た、参加した、または介入した場合だけ付与する。

## 巻き戻るもの

カシオペアで戻るものは次の通り。

- そのループ内のイベント進行
- エリア状態
- 人物のその時点の行動
- そのループ内の混雑や人流
- 未確定の報酬や結果

## 維持するもの

ループをまたいで維持するものは次の通り。

- プレイヤーが知った時刻、場所、条件
- イベントを見た、失敗した、達成した記録
- 原作再現に関わる既定進行結果
- 実績
- 特定イベントの経験済み記録
- 次ループで開く派生、合体、波及の可能性
- アイテム入手済み記録やキーアイテム

ランダム突発イベントの経験済み記録を維持する場合も、同じ時間と場所で同じ出来事が再発生することは保証しない。
記録は、関連する噂が聞ける、発生確率を上げる手段が開く、成長方向や合流先が増える、といった形で使う。

## 展開可能性

展開可能性は、世界内でそのまま起きた事実ではなく、プレイヤーの経験によって次ループで開く可能性である。

例:

```text
1ループ目:
武道会で準優勝する。

巻き戻し後:
世界は武道会前に戻る。
ただし、準優勝経験済み記録は残る。

2ループ目以降:
武道会や関連人物に関わると、取材、噂、注目イベントが開きやすくなる。
```

この仕組みにより、時間は戻っているが、プレイヤーの遊びは前に進む。

経験済み記録はイベントの再実行を禁止するためには使わない。同じループ中は完了済みイベントを再実行せず、カシオペアでイベント前へ戻った新しいループでは、通常の発生条件を満たすことで再び実行できる。

巻き戻し後にイベントを完了した場合、イベント報酬、好感度、エリアの盛り上がりなどの反復可能な効果を毎回反映する。チャオ発見、情報取得、CG取得などの解禁情報は一度取得すれば維持する。

原作既定進行では、プレイヤーが武道会に参加していないループでも、時系列上はネギが準優勝した結果として午後の取材クルー追跡が発生する。
この場合、準優勝後の世界反応は発生するが、プレイヤーは武道会を体験済みにはならない。
武道会の専用会話、報酬、実績、勝敗に関わる細かな差分は、実際に参加した場合だけ得る。

## 固定イベントの変化

定時イベントや原作再現イベントでも、ループ間変化を持てる。

- 1回目は小さく発生する。
- 経験後は、関連人物や噂が増える。
- 別の時間に先回りすると、合体先が変わる。
- 事前準備により、イベントの成長方向が変わる。

固定イベントを毎回同じ再生にしすぎると、ループの面白さが弱くなる。
一方で、毎回大きく変えすぎると予定を覚える遊びが弱くなる。
そのため、発生時刻や基礎展開は安定させ、派生、波及、反応で変化を出す。

クラスメイトとの約束や出し物は、スケジュール帳に登録された予定として扱う。
プレイヤーがその場へ行かなかった場合でも、原作既定進行に必要な予定は時間経過で進行済みになる。
一方で、プレイヤーがその場で得る会話、好感度、報酬、詳細な体験記録は発生しない。

## ランダム突発イベントの変化

ランダム突発イベントは、ループごとに再抽選する。
重要な突発イベントであっても、前ループで発生したことを理由に同じ発生を固定しない。

一方で、一度遭遇した出来事を完全に無意味にはしない。
次ループでは、次のような形で出会いやすさや広がりを変化させる。

- 関連する噂や目撃情報を聞きやすくなる。
- 特定カテゴリの突発イベントを発生しやすくするアイテムや条件が開く。
- 同種の突発イベントが発生したとき、成長先や合流先が増える。
- 重要な突発イベントに関わる人物や場所への誘導が増える。

これにより、ランダム性によるレア感を残しつつ、出現頻度が低すぎることによる遊びにくさを抑える。
