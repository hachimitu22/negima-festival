# 巻き込み頻度設計

## 目的

麻帆良祭のわちゃわちゃ感を、予定していた行動の途中で別の出来事に巻き込まれる体験として作る。

## 基本方針

プレイヤーは定時イベント、営業時間付き出店、教師仕事から次の予定行動を選ぶ。ハプニングは目的一覧へ並べず、移動経路、滞在場所、実行中の予定行動へ接続する。

プロトタイプでは場所選択式で巻き込みを検証する。
場所を選択した直後に到着せず、必ず移動中フェーズを挟む。
移動中フェーズでは、移動時間、通過エリア、周辺イベント、混雑、人流を処理し、巻き込みがなければ目的地へ到着する。
到着後に選んだ行動の実行中にも、ランダムまたは条件付きで別イベントが割り込む。

直接対応する予定外の出来事は原則1件とする。世界内では別の出来事も進行するが、割込中に別の割込を開始しない。

## 巻き込み段階

| 段階 | プレイヤーへの影響 |
| --- | --- |
| 軽微 | 群衆、歓声、通行速度の変化として通過する |
| 中程度 | 対応または迂回を選ぶ。判断中は時間を止め、迂回には時間を使う |
| 重大 | 現在行動を強制中断し、最初の影響を受けた後に対応を選ぶ |

## 巻き込み種別

### 移動中巻き込み

移動中巻き込みは、目的地へ向かう途中で発生する。

- 通路の混雑で足止めされる。
- 近くのハプニングに呼び止められる。
- 遠くで成長したイベントが通行ルートへ波及する。
- 同行クラスメイトが別の出来事に反応して寄り道を提案する。

移動中巻き込みに関わると、元の目的地への移動は中断状態になる。
巻き込み解決後、元の目的地へ向かうか、別の目的へ切り替えるかを選べる。

### 行動中巻き込み

行動中巻き込みは、到着後に選んだ行動の実行中に発生する。

- 出店利用中に別イベントが合流する。
- クラスメイトとの会話中に周囲の騒ぎが大きくなる。
- 教師仕事中に別のトラブル対応が発生する。

行動中巻き込みでは、元の行動を中断、短縮、再開、離脱のいずれかで扱う。

## 頻度制御

- 予定行動を持たない状態では重大な巻き込みを発生させない。
- 中程度以上の巻き込みを連続させない。
- 同じ移動中に発生する直接割込は1件を基準とする。
- 同じ行動中に発生する直接割込も1件を基準とする。
- 遠方の出来事は人流と通路を通って到達した場合だけ巻き込みへ変える。
- ランダムな強制割込だけで定時イベントを完全に失敗させない。

## 見逃しとの関係

巻き込みで定時イベントへ遅れた場合は、開始後5分まで通常参加できる。その後も終了前なら途中参加できる。参加済みイベントが割込中に終了時刻を迎えた場合は、短縮した終了段階へ復帰する。
