# クラスメイトステータス

スケジュールとメイン操作の間に、クラスメイトの現在状態を表示する。

表示項目はクラスメイト名、現在エリア、現在状態、好感度とする。

小太郎もクラスメイトと同じアクターとして表示する。武道会などのイベント進行中は、イベント専用の状態を優先して表示する。

現在状態は次のいずれかを表示する。

- 出し物中
- デート待ち
- 待機中
- 聞き込み可能
- 固定配置
- 会話中
- 自由行動

出し物中のクラスメイトは、予定で指定されたエリアを表示する。自由行動中のクラスメイトは、現在のランダム配置エリアを表示する。チャオ探索中の固定配置人物は、聞き込み可能な状態として表示する。

状態または好感度が変化した場合だけ表示を更新する。座標は表示しない。
