# 用語集(キャラクター)

## ネギ・スプリングフィールド
魔法先生ネギま！の主人公、イギリスのウェールズ出身の10才の男の子。
魔法使いとしてマギステルマギとなる修行の一環として麻帆良学園の女子中等部で先生をする。
愛称はネギ君、ネギ先生、ネギ坊主など。

## 麻帆良学園女子中等部3-A

31人の生徒が在籍している。
どの生徒も個性的。
