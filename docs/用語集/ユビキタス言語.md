# ユビキタス言語

## 文書情報

- 仕様状態: 確定
- 対象: ゲーム内の概念と振る舞い
- 対象外: JavaScriptのクラス、API、保存形式、rendererの構造

この文書は、企画、仕様、設計、実装で同じ意味の用語を使用するための正本である。
表記には[ドメイン記述ミニ言語](https://scrapbox.io/kawasima/%E3%83%89%E3%83%A1%E3%82%A4%E3%83%B3%E8%A8%98%E8%BF%B0%E3%83%9F%E3%83%8B%E8%A8%80%E8%AA%9E)を使用する。
ここでの `data` はゲーム内の概念、`behavior` はゲーム上の振る舞いを表し、実装上の型や関数を指定しない。

## 基本概念

```text
// 麻帆良祭の開始を0、終了を72とする時間
data ゲーム時間 = 時間

// 0以上。カシオペアを使って時間を戻した回数
data ループ回数 = 整数

data 祭りの進行 = ゲーム時間
AND ループ回数

data 場所 = 場所名
AND List<移動可能先>

data 登場人物 = 生徒 OR 教師

data 生徒 = 名前
AND 出席番号
AND 現在地
AND 好感度

data 教師 = 名前
AND 現在地

data プレイヤー = 現在地
AND MP
AND MahoPayポイント

// 0から最大MPまで
data MP = 整数

// 0以上。麻帆良祭中に使用するゲーム内通貨
data MahoPayポイント = 整数

data 現在地 = 場所
```

## 三日間とカシオペア

```text
data 祭りの状態 = 開催中 OR 終了

data カシオペア使用結果 = 時間遡行成功 OR MP不足

behavior 時間を進める = 開催中の祭り AND 経過時間 -> 開催中の祭り OR 終了した祭り

behavior カシオペアを使う = 祭りの進行
AND プレイヤー
AND 実行中イベント?
-> カシオペア使用結果
```

「三日間」はゲーム内時間で72時間の開催期間を表す。
「ループ」はカシオペアによってその期間の一部をやり直すことを表し、ゲーム全体の初期化を意味しない。

## 会話

```text
data 会話 = 会話シーン OR フィールド会話

data 会話シーン = 会話相手
AND List<メッセージ>
AND 選択肢?

data フィールド会話 = 会話相手
AND List<メッセージ>
AND 選択肢?

data 会話結果 = 完了した会話
AND 選択結果?

behavior 会話シーンを始める = プレイヤー
AND 同じ場所にいる登場人物
-> 会話シーン

behavior 会話を進める = 実行中の会話シーン
AND メッセージ送り OR 選択
-> 実行中の会話シーン OR 会話結果
```

「会話」は会話シーンとフィールド会話をまとめて説明するときだけ使用する。
両者は表示方法だけでなく、ゲーム進行上の役割が異なる独立した概念とする。

## イベントとタスク

```text
data イベント = 単発イベント OR 継続イベント

data 単発イベント = 開始 AND 結果

data 継続イベント = 配達イベント OR 同行イベント OR 見回りイベント

data 実行中イベント = 実行中配達 OR 実行中同行 OR 実行中見回り

// 達成すべき目的。イベントと同義ではない
data タスク = 目的
AND 達成条件
AND 失敗条件?

data 配達イベント = 提示された配達
OR 実行中配達
OR 成功した配達
OR 失敗した配達

data 実行中配達 = 差出人
AND 受取人
AND 配達物

data 同行イベント = 提示された同行
OR 実行中同行
OR 成功した同行

data 実行中同行 = 同伴者
AND 目的地

data 見回りイベント = 実行中見回り
OR 成功した見回り

data 実行中見回り = List<見回り先>
AND 報酬MahoPayポイント

data 見回り先 = 場所
AND 訪問状態

data 訪問状態 = 未訪問 OR 訪問済み

behavior 配達を引き受ける = 提示された配達 -> 実行中配達

behavior 配達を断る = 実行中配達 -> 失敗した配達

behavior 配達物を渡す = 実行中配達
AND 受取人との完了会話
-> 成功した配達

behavior 同行を始める = 提示された同行 -> 実行中同行

behavior 同行を完了する = 実行中同行
AND 目的地
AND 同伴者との完了会話
-> 成功した同行

behavior 見回りを始める = ゲーム開始 OR 定期発生時刻
AND 実行中見回りがない
-> 実行中見回り

behavior 見回り先を訪問する = 実行中見回り
AND 見回り先への移動
-> 訪問済みの見回り先

behavior 見回りを完了する = 実行中見回り
AND 全見回り先が訪問済み
-> 成功した見回り
AND MahoPayポイント
```

イベントはゲーム上の出来事、タスクは達成すべき目的を表す。
配達、同行、見回りを同じ「イベント」に分類しても、実装上の共通基底型や継承関係は要求しない。

## 補助用語

| 用語            | 定義                                                   |
| --------------- | ------------------------------------------------------ |
| MahoPayポイント | 麻帆良祭中の報酬と支払いに使用するゲーム内通貨         |
| 好感度          | 生徒とプレイヤーの関係を表す数値                       |
| 実行中イベント  | 開始済みで、まだ成功または失敗していない継続イベント   |
| 会話相手        | 現在の会話に参加し、プレイヤーが話しかけた登場人物     |
| 同伴者          | 同行イベント中にプレイヤーと同じ場所へ移動する登場人物 |
| 差出人          | 配達を依頼する登場人物                                 |
| 受取人          | 配達物を受け取る登場人物                               |
| 見回り先        | 見回りイベントで訪問するよう指定された場所             |
| ハプニング      | 麻帆良祭中に突発的に発生する問題または出来事           |
| 先生タスク      | ネギが教師として対応する仕事                           |

キャラクター固有の名前や原作上の説明は[キャラクター用語](魔法先生ネギま/キャラクター/README.md)を参照する。
