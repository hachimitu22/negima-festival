# NoticeBoardEvent（連絡掲示イベント定義）

## 文書情報

- 設計状態: 確定
- 対象: `src/gameDomain/mainGameScene/event/noticeBoardEvent.js`

## 目的

汎用の`BranchEvent`を使って、基本設計の[連絡掲示イベント](../../../基本設計/イベント/連絡掲示イベント.md)に対応するイベント定義を生成する。
`BranchEvent`自体を連絡掲示専用にせず、連絡掲示固有の名称、タスクID、タスク定義、初期目的地差し替えだけをこのモジュールに閉じ込める。

## 公開契約

```js
createNoticeBoardEvent(id, { currentLocationId, startHours })
```

`id`、開始時刻、開始時の現在地を受け取り、`type: 'notice-board'`、`name: '連絡掲示イベント'`を持つ`BranchEvent`を返す。

## タスク定義

- 紛失した連絡掲示を探す: 図書室、4時間、成功で「連絡掲示を届ける」、失敗で「代替の集合場所を確認」。
- 連絡掲示を届ける: 職員室、3時間、成功で「最終引き渡しを確認」、失敗で「結果を報告」。
- 代替の集合場所を確認: 休憩所、3時間、成功で「結果を報告」、失敗で終了。
- 最終引き渡しを確認: 世界樹、5時間、成功または失敗で終了。
- 結果を報告: ホール、2時間、成功または失敗で終了。

開始時の現在地が図書室の場合、初期タスクの目的地だけ職員室へ差し替える。

## 依存関係

- `BranchEvent`: 分岐チェーンの実行とsnapshot生成を担当する。
- `locations`: タスク目的地の検索と、初期目的地差し替え時の代替地点取得に使う。
