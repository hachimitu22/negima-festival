# AGENTS

## テストコード作成方針

### 単体テストコード

- 実行時間を短くし、外部I/O、実時間の待機、DOM、ゲームループへ依存させないでください。
- 各テストを他のテストから隔離し、実行順、共有可変状態、他のテストが残した状態へ依存させないでください。
- 古典学派の方針に従い、小さなインメモリの協力オブジェクトは実物を使用してください。
- ライブラリ製、手製を問わずモックを使用しないでください。
- privateな実装ではなく、公開APIから観察できる振る舞いを検証してください。
- テスト設計のTest Suiteを`describe`または`suite`へ、Test Caseを`test`または`it`へ対応させてください。
- suiteは分類だけに使用し、case間でfixture、インスタンス、状態を共有しないでください。
- 単体テストコードはAAA形式とし、各フェーズの開始位置へ`// Arrange`、`// Act`、`// Assert`のコメントを記述してください。

### 統合テストコード

- 明示的な依頼があるまで統合テストコードを作成しないでください。
